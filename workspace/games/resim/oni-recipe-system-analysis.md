# 缺氧（Oxygen Not Included）「配方」系统深度分析

> ONI 没有传统意义上的"配方"界面。所有物质转化由物理模拟驱动——温度、相变、质量守恒（部分遵守）、重力分层层层叠加，形成了一套独特的**涌现式生产系统**。

---

## 一、转化建筑（Transformation Building）全景

### 1.1 分类统计

| 类别 | 建筑数量 | 核心特征 |
|------|----------|----------|
| **生命维持** | ~8 | 氧气生成、水净化、CO2 处理 |
| **食物生产** | ~15 | 种植（~10种作物）+ 烹饪（烤炉、燃气灶、电动烤架） |
| **工业精炼** | ~12 | 金属精炼、玻璃锻造、塑料制造、钢铁冶炼 |
| **发电** | ~10 | 煤/氢/天然气/石油/蒸汽涡轮/太阳能/核能 |
| **航天** | ~6 | 火箭燃料、氧化剂、舱体制造 |
| **杂项** | ~5 | 服装、医疗、装饰 |

总计约 **55-60 个转化建筑**（不含变体升级），每个建筑本质上是一个**黑箱转化器**：输入物质 + 条件（电力/温度/复制人劳动）→ 输出物质。

### 1.2 与 Factorio 的本质差异：「无固定配方」哲学

| 维度 | Factorio / Satisfactory | 缺氧 |
|------|------------------------|------|
| **配方定义** | 明确的 `input × N → output × M`，配方固定 | 建筑定义了转化率，但输入物可以"任意来源"，输出受物理环境影响 |
| **比例问题** | 玩家计算比率（assembler 配比） | 玩家管理**可持续性**（能否永久运行？副产物是否会堵塞？） |
| **"过量"处理** | 通常不存在——你生产的就是你需要的 | **核心问题**——副产物必须被消费、存储、排出或摧毁 |
| **品质维度** | 不存在（所有产出一致） | 物质带着**温度**这一隐含属性；同样 1kg 水，1°C vs 99°C 截然不同 |
| **失败模式** | 产线停滞（资源不足）或缓存溢出 | 管道破裂（相变）、设备过热损坏、气压失衡、生物死亡 |
| **物理层** | 无（或仅电力负载） | 温度、气压、重力、光照、病菌、装饰度、气体分压 |

**核心洞察**：Factorio 的配方是一棵**单向树**（原材料→中间品→成品）；ONI 的配方是一张**带物理约束的有向图**，边的方向取决于温度梯度和物质形态。

## 二、温度依赖输出：热力学作为「隐藏配方」

### 2.1 固定输出温度机制

ONI 中约 **80%** 的转化建筑以**固定温度**输出产物，无视输入温度。这是整个热力学游戏的基础。

#### 关键案例

| 建筑 | 输入 | 输出温度 | 热力学效果 |
|------|------|----------|------------|
| **电解器** | 任意温度水 | 70°C O₂ + H₂ | 输入<70°C = 热创造；输入>70°C = 热删除 |
| **蒸汽涡轮机** | ≥125°C 蒸汽 | 95°C 水 | 热删除 ~90%（仅10%转化为电力） |
| **石油精炼器** | 任意温度原油 | 75°C 石油 | 输入>75°C = 热删除 |
| **聚合物压机** | 任意温度石油 | 200°C 塑料 + 蒸汽 + CO₂ | 大量热创造 |
| **金属精炼器** | 任意温度矿石 | 40°C 精炼金属 | 将巨大热量排入冷却液 |
| **肥料合成器** | 任意温度污水+泥土 | 30°C 肥料 | 热删除（低温输出） |
| **碳素脱离器** | 任意温度水+CO₂ | 40°C 污水 | 通常为热创造 |
| **乙醇蒸馏器** | 任意温度木材 | 73.4°C 乙醇 + 93.4°C 污土+CO₂ | 热创造 |

### 2.2 热删除/热创造的元游戏

**核心机制**：固定输出温度 + 物质比热容差异 = 净热量变化。

#### 经典案例：电解器热删除

```
输入：1 kg/s 水 @ 95°C（来自冷蒸泉）
比热容：水 4.179 DTU/g·°C
输出：0.888 kg/s O₂ @ 70°C + 0.112 kg/s H₂ @ 70°C
比热容：O₂ 1.005, H₂ 2.400

Q_in  = 1000 × 4.179 × 95   = 397,005 DTU
Q_out = 888 × 1.005 × 70 + 112 × 2.400 × 70
      = 62,461 + 18,816 = 81,277 DTU
净热删除 = ~315,728 DTU/s（~80% 热删除！）
```

#### 经典案例：聚合物压机热创造

```
输入：0.833 kg/s 石油 @ 75°C
输出：0.25 kg/s 塑料 @ 200°C + 0.25 kg/s 蒸汽 @ 200°C + 0.25 kg/s CO₂ @ 200°C
→ 200°C 是远超基础温度的输出，所有输出物质的比热容加起来 ≈ 大量热创造
→ 聚合物压机是基地过热的主要元凶之一
```

### 2.3 温度管理作为「隐藏配方」

温度管理不是可选的——它是每个产线的**隐性投入**：

- **冷却液选择**：污水（-20→120°C）、石油/原油（-57→540°C）、超级冷却剂（-271→437°C）各有温域
- **冷却方式**：液冷机+蒸汽涡轮（最常见）、反熵热量中和器（限量）、冰-E 风扇（临时）
- **热容缓冲**：利用高比热容物质（水4.179、超级冷却剂8.440）作为热汇
- **热隔离**：陶瓷隔热砖、真空夹层、液锁气闸

**结论**：在 ONI 中，"配方"不是 `A+B→C`，而是 `A+B→C + 需要处理的ΔQ热量 + 需要控温的环境`。温度是每个配方的**第三维输入**。

## 三、转化链深度分析

### 3.1 最长转化链

#### 链条 1：原油→超级冷却剂（8步）

```
原油(原油泉)
  ↓ 油井/石油精炼器 (需要水 + 电力)
石油
  ↓ 聚合物压机 (依赖石油的副产物管理)
塑料
  ↓ 分子熔炉 (需要异丁烯 + 富勒烯 → 太空采集)
塑料+异丁烯+富勒烯
  ↓ 分子熔炉
超级冷却剂
  ↕ 超级冷却剂可用于液冷机 → 实现极低温冷却
  ↕ 超级冷却剂可用于制造隔热质(与异丁烯组合)
```

实际最长链条如果算上**全产业链自给自足**：
```
原油 → 石油 → 塑料(聚合物压机) → 电路板(制造站)
石油 → 乙醇(通过特定流程) → ……
原油 → 石油 → 酸气(>540°C) → 甲烷(冷却) → 天然气 → 发电机
```

#### 链条 2：矿物→钢铁（5步）

```
矿物原料(任意)
  ↓ 采矿/挖掘
沉积岩
  ↓ 碎石机
沙子
  ↓ 玻璃熔炉
玻璃(用于太阳能板/装饰)
  或
金属矿石
  ↓ 碎石机 → 沙子 + 精炼金属(50%效率)
  或
金属矿石
  ↓ 金属精炼器 → 精炼金属(100%效率)
  ↓
精炼金属 + 铁 + 精炼碳
  ↓ 金属精炼器（需要石灰）
钢铁
  石灰来源: 化石(碎石机) 或 螃蟹壳(螃蟹养殖)
```

#### 链条 3：污染→纯净（无限循环）

```
污水 → 水筛 → 净水 + 污土
污土 → 堆肥 → 泥土
净水 → 电解器 → O₂ + H₂
H₂ → 氢发电机 → 电力
O₂ → 复制人呼吸 → CO₂
CO₂ → 碳素脱离器(加水) → 污水
污水 → …(闭环！)
```

### 3.2 链深度对比

| 游戏 | 最长链步数 | 分支数量 | 副产品复杂度 |
|------|-----------|---------|-------------|
| **Factorio** | ~12（原矿→三级插件→蜘蛛机甲） | 大量平行分支 | 低（仅铀处理有副产物） |
| **缺氧** | ~8（原油→超级冷却剂） | 少但交叉耦合 | **极高**（几乎每步都有副产物） |
| **Satisfactory** | ~10 | 大量平行分支 | 低（少数有副产物） |
| **Minecraft (Tech Mods)** | ~15（GregTech 类） | 极高 | 中-高 |

ONI 的链条**不是垂直深度取胜**，而是**横向耦合取胜**——一个建筑的副产物是另一个建筑的原料，形成网络而非树。

## 四、副产物驱动设计（Byproduct-Forward Design）

这是 ONI 最独特的设计哲学：**每个生产建筑的核心挑战不是"如何获得输出"，而是"如何处理副产品"**。

### 4.1 副产品网络映射

#### 核心交叉连接

```
                    ┌─────────────────────────┐
                    │       电解器              │
                    │  水→O₂(70°C)+H₂(70°C)    │
                    └───────┬───────┬───────────┘
                            │       │
                  O₂(呼吸)  │       │ H₂
                            ▼       ▼
                   复制人═══╗   ┌──────────────┐
                    ║      ║   │  氢气发电机    │
                    ║CO₂   ║   │  H₂→电力      │
                    ║      ║   └──────────────┘
                    ▼      ║
              ┌──────────┐ ║
              │碳素脱离器 │◄╝  CO₂+水→污水
              └────┬─────┘
                   │污水
                   ▼
              ┌──────────┐
              │  水筛     │
              │污水→净水+污土│
              └────┬─────┘
                   │
          ┌────────┼────────┐
          ▼        ▼        ▼
      净水(回环)  污土      污土
                堆肥→泥土  螃蟹→石灰
```

#### 主要副产品对应表

| 源建筑 | 副产品 | 处理方式 | 能否彻底消除 |
|--------|--------|----------|:----------:|
| **电解器** | H₂ | 氢气发电机 / 火箭燃料 / 排入太空 | ✅ |
| **天然气发电机** | CO₂ + 污水 | CO₂→浮游生物/碳素脱离器/排太空；污水→水筛 | ✅ |
| **石油发电机** | CO₂ + 污水(大量) | 同上 | ✅ |
| **煤发电机** | CO₂ | 碳素脱离器 / 浮游生物 | ✅ |
| **聚合物压机** | 蒸汽(200°C) + CO₂ | 蒸汽涡轮 / 直接冷却 | ⚠️ 热污染 |
| **石油精炼器** | 天然气 | 天然气发电机 | ✅ |
| **乙醇蒸馏器** | 污土 + CO₂(93.4°C) | 污土→螃蟹饲料/堆肥；CO₂→处理 | ⚠️ 热污染 |
| **金属精炼器** | 冷却液热量 | 蒸汽涡轮回收 | ✅（转化回收） |
| **核反应堆** | 核废料(辐射) | 长期储存 / 辐射利用 | ❌ 永久储存问题 |

### 4.2 「逆向配方图」：管理副产物才是真正的解谜

在 Factorio 中，玩家问：**"我怎样生产更多的 X？"**
在 ONI 中，玩家问：**"如果我生产 X，Y 会堆积吗？Y 能用来做什么？Z 会不会过热？"**

这种设计产生了几种典型挑战：

1. **CO₂ 下沉陷阱**：CO₂ 是最低密度气体，会在基地底部堆积，若不处理，缓慢窒息底层复制人
2. **氢气上浮**：H₂ 是最轻气体，在基地顶部聚集，若不利用/处理，浪费可燃气
3. **污水管理**：厕所、淋浴、发电机都产出污水——必须循环处理，否则水资源枯竭
4. **热污染扩散**：高温输出物质在管道中运行时会与环境换热——需要一个中央冷却方案
5. **物质相变灾难**：如果环境温度突破物质相变点，管道破裂是【不可逆】的——需要修复+清理

**关键洞察**：ONI 的"反配方图"不是构建一个完美的输入输出平衡，而是**永远保持每个副产物的消费量 ≥ 生产量**。这种不等式约束让产线设计变得极其有趣。

## 五、畜牧「配方」：Ranching as Production

### 5.1 畜牧建筑体系

畜牧是 ONI 中与传统"配方"最不相同的系统——生物通过**代谢转化**物质：

| 生物 | 输入 | 转化物 | 周期 | 温度限制 |
|------|------|--------|------|----------|
| **草质螃蟹** | 泥土/污土 | 煤炭 | 消耗饮食 | -30~100°C |
| **石壳螃蟹** | 矿物(沉积岩/火成岩等) | 煤炭(50%)+蛋 | — | -30~100°C |
| **光滑螃蟹** | 金属矿石 | 精炼金属(75%转化率!) | — | -30~100°C |
| **毛茸茸兔** | 泥土(无产出，仅装饰) | — | — | 15~40°C |
| **浮游生物** | CO₂ | 原油/石油(取决于变体) | 呼吸CO₂ | -55~100°C |
| **帕库鱼** | 藻类/种子 | 污土+蛋 | — | -30~80°C |
| **喷浮飞鱼** | 污染氧 | 菌泥 | — | — |
| **草钻** | — | 塑料(长鳞) | — | — |

### 5.2 变体系统（Morph）：平行生产路径

每个畜牧物种有 **2-4 种变体（morph）**，由饲料概率触发：

#### 螃蟹（Hatch）家族

```
螃蟹蛋
├── 草质螃蟹 (Sage Hatch) —— 消耗有机物质 → 煤炭
├── 石壳螃蟹 (Stone Hatch) —— 消耗矿物 → 煤炭(更高效)+更多蛋
├── 光滑螃蟹 (Smooth Hatch) —— 消耗金属矿石 → 精炼金属(75%)!
└── 暗影螃蟹 (特殊的深渊变体)
```

**设计洞察**：三只螃蟹可实现不同的生产目标：
- 需要煤炭供电 → 石壳螃蟹（最高煤炭产率）
- 需要精炼金属但不想建金属精炼器 → 光滑螃蟹（免电力、免热量！但转化率75%）
- 想处理多余的有机废料 → 草质螃蟹

#### 浮游生物（Slickster）家族

```
浮游生物蛋
├── 普通浮游生物 —— CO₂ → 原油
├── 熔岩浮游生物 —— CO₂+高温 → 石油
└── 长毛浮游生物 —— O₂ 呼吸 → 原油(更高效)
```

**关键决策**：熔岩浮游生物产生石油（而非原油）——跳过了石油精炼器这步！但需要300°C以上的温度环境。

### 5.3 畜牧 vs 机械：平行生产路径对比

以**精炼金属**为例：

| 方式 | 输入 | 输出 | 电力 | 热量 | 劳动 | 转化率 |
|------|------|------|:----:|:----:|:----:|:------:|
| 金属精炼器 | 金属矿石+冷却液 | 精炼金属 | 1200W | **极高** | 操作 | 100% |
| 碎石机 | 金属矿石 | 精炼金属+沙子 | 240W | 中 | 操作 | 50% |
| 光滑螃蟹 | 金属矿石 | 精炼金属(75%) | 0W | **零** | 仅照顾 | 75%+蛋 |
| 火箭回收 | 太空采集 | 精炼金属 | — | — | — | 依赖太空 |

**设计意义**：同一个生产目标存在多条路径，每条路径有不同的副产物和风险——"配方"不是唯一的。这是 Factorio 完全不具备的设计维度。

## 六、涌现系统（Emergent Systems）

ONI 最精彩的时刻，是玩家将 5-10 个看似独立的建筑组合成**自维持生产系统**——这是任何预定义配方都无法达成的"元配方"。

### 6.1 SPOM：自供氧模块（Self-Powering Oxygen Module）

**组合建筑**：电解器 ×2 + 氢气泵 + 氢气发电机 + 气泵 ×4 + 气体过滤器 + 智能电池 + 变压器

```
                     ┌──────────────┐
  水 →│  电解器×2    │→ O₂ (70°C, 888g/s) → 气泵 → 基地通风
       │              │→ H₂ (70°C, 112g/s) → 气泵 → 气体过滤器──→ H₂ → 氢气发电机
       └──────┬───────┘                                │              ↓
              自动化: 电池电量>90% → 关闭发电机          │         ┌──────────┐
              自动化: 气压>2000g → 停止气泵              │         │ 电力自给！│
                                                         │         └──────────┘
                                                         │
                                              多余 H₂ ←──┘→ 存罐/火箭燃料/排太空
```

**精妙之处**：
- H₂ 产量永远超过发电机消耗所需（H₂副产 > 发电用H₂）
- 多余 H₂ → 净能源正产出（这就是"自供氧→发电"）
- O₂ 冷却（70°C输出需要冷却到适宜温度）→ 扩展为冷却版 SPOM
- 热力学微调：电解器放在氢气环境中导热更快

**涌现性质**：单独看每个建筑都没有"关闭"逻辑——组合后的自动化规则使得整个模块成为一个**有记忆的自治系统**。

### 6.2 工业桑拿（Industrial Sauna）

**组合建筑**：蒸汽涡轮 ×2 + 金属精炼器 + 聚合物压机 + 玻璃熔炉 + 窑炉 + 液锁 + 蒸汽室

```
                   ┌─────────────────────────────────┐
                   │        蒸汽室(>125°C)             │
                   │                                   │
                   │  ┌──────┐  ┌──────┐  ┌─────┐     │
                   │  │金属  │  │聚合物│  │玻璃 │     │
                   │  │精炼器│  │压机  │  │熔炉 │     │
                   │  └──┬───┘  └──┬───┘  └──┬──┘     │
                   │     │ 热量    │ CO₂+蒸汽│ 热量    │
                   │     └────┬────┘         │         │
                   │          ▼              │         │
                   │    ┌──────────┐         │         │
                   │    │蒸汽涡轮×2│◄────────┘         │
                   │    │(200°C蒸)│                     │
                   │    └────┬─────┘                    │
                   │         │ 95°C水+电力              │
                   └─────────┼──────────────────────────┘
                             ▼
                    热水循环回蒸汽室
```

**精妙之处**：
- 所有高温工业放在蒸汽室中，热量不会散失到基地
- 蒸汽涡轮将"废热"转化为电力（回收）
- 复制人穿太空服进入，不会被高温烫伤
- CO₂ 被其他设备处理（浮游生物/碳素脱离器），蒸汽则留在室中
- **一个系统同时解决了冷却、发电、气体管理三个问题**

### 6.3 石油锅炉（Petroleum Boiler）

**组合建筑**：油井 + 逆流换热器 + 热源（火山/熔岩/液金精炼器）+ 液体泵 + 酸气冷凝器（可选）

```
原油(~90°C) ──────────────────────┐
         逆流换热(原油管与热石油管相邻)│ 原油被预热至~400°C
                                   ▼
                          ┌──────────────┐
                          │ 热源界面       │ → 原油 >400°C → 闪蒸为石油
                          │ (火山/岩浆)   │    （可能产生酸气 >540°C）
                          └──────┬───────┘
                                 ▼
                 石油(~400°C) ──→ 逆流换热(冷却输入原油)
                                 │
                                 ▼
                         石油(~110°C) → 液体泵 → 储存/使用
```

**精妙之处**：
- 直接跳过石油精炼器（省电、省空间）
- **100% 转化率**（vs 精炼器的 50%）
- 利用逆流换热回收热量，大幅提高热效率
- 需要精确控温（>400°C但<540°C，否则产生酸气）
- **涌现出来的"管道温度计+机械门+温度传感器"温控电路**

### 6.4 涌现系统的共同特征

1. **跨模块耦合**：一个系统的"废热"是另一个系统的"输入"
2. **热力学驱动**：温度梯度是系统自维持的能量来源
3. **自动化闭环**：AND/OR/NOT门 + 传感器 = 复杂行为
4. **临界点设计**：相变阈值（100°C蒸发、400°C石油化、540°C酸气化）定义了系统的"操作窗口"
5. **无法复制、只能理解**：每个基地的地形、泉种不同，系统需要因地制宜

## 七、Mod 扩展性

### 7.1 Steam Workshop 生态

ONI 拥有活跃的 Steam Workshop 社区。Mod 的能力：

| 能力 | 支持程度 | 示例 |
|------|:------:|------|
| 新增建筑（含自定义转化） | ✅ 完全支持 | 新发电机、新精炼器 |
| 新增物质/元素 | ✅ | 新液体、气体、固体 |
| 新增动植物 | ✅ | 新作物、新畜牧动物 |
| UI 改良 | ✅ | 蓝图、管道覆盖层增强 |
| 游戏规则修改 | ✅ | 难度调整、地图生成 |
| 新增物理/机制 | ⚠️ 有限 | 受引擎限制 |
| 多线程/性能优化 | ⚠️ 困难 | 游戏单线程为主 |

### 7.2 知名 Mod

1. **Piped Output / Piped Everything**：让几乎所有建筑支持管道输入输出——消除"复制人搬运"瓶颈
2. **Customize Buildings**：自定义建筑属性（速度、效率、热量产出）
3. **Blueprints**：蓝图系统（原版不支持）
4. **Bigger Camera Zoom**：更大的缩放范围
5. **Geyser Tools**：间歇泉精确信息
6. **Chain Deconstruction**：连锁拆除
7. **Diseases Restored**：恢复被削弱前的病菌机制
8. **Lights Out**：黑暗模式
9. **Spaced Out! (官方DLC)**：虽非mod，但扩展了整个航天+辐射+核能系统

### 7.3 限制

- **物理引擎不可扩展**：不能新增相变规则、热传导公式、气体扩散算法
- **单线程瓶颈**：大规模基地性能受限于游戏引擎的单线程设计
- **元素网格系统**：物质以 1×1 网格存在（非流体），不能创建真正的连续液体物理

## 八、设计评价

### 8.1 最佳设计决策

1. **固定输出温度** —— 悖论式设计，创造了整个热力学元游戏
   - 如果输出温度 = 输入温度，热管理变得平凡
   - 固定温度迫使玩家设计冷却方案，冷却方案本身成为了一种"生产"

2. **副产物驱动（Byproduct-Forward）** —— 玩家不是在管理生产，而是在管理**过剩**
   - 将 Factorio 的"比率计算"变成了"负反馈管理"
   - 没有完美的自给自足，只有无限逼近

3. **相变作为生产路径** —— 临界阈值创造了涌现玩法
   - 原油 → 402.85°C 闪蒸为石油：它不是"配方"，是**发现**
   - 许多玩家第一台石油锅炉是"偶然"触发相变后反向工程的

4. **一格一物质（One Element Per Tile）** —— 简化但强大的模拟
   - 每格仅能存一种物质（按密度分层），创造了气体/液体分层
   - CO₂下沉、H₂上浮——简单的规则 → 复杂的宏观行为

5. **畜牧作为"活的配方系统"** —— 生物有温度需求、食物需求、繁殖周期
   - 生物不是建筑，不能随意开关——需要持续维护
   - 变体系统创造了多种生产同一产物的路径

### 8.2 最差设计决策 / 局限

1. **缺乏配方可发现性** —— 新玩家无法在游戏内了解"原油在400°C变成石油"
   - 依赖外部 wiki 和社区知识
   - 缺少一个内置的"可做什么"浏览系统

2. **管道比率不透明** —— 液体/气体管道的流速（1kg/s or 10kg/s）、热量交换公式都不在游戏内说明
   - 导致新手困惑：为什么我的管道阻塞了？

3. **后期性能** —— 单线程引擎 + 大规模基地 = 帧率下降
   - 每个 tile 都需要计算温度、质量、病菌等，规模到达一定量级后不可持续

4. **自动化逻辑门有限** —— AND/OR/NOT/XOR + 滤波器 + 缓冲器 vs Factorio 的组合器网络
   - Factorio 的组合器可以构建图灵完备的电路
   - ONI 的自动化更偏向"阈值触发"，缺少复杂的信号处理

5. **缺乏可控性的物质销毁** —— 唯一"真正"的物质消除方式是排入太空（需要航天）
   - 许多场景需要"虚空处理"（将多余气体/液体喂给不消耗它的设备来"消除"——算不上bug，但说明系统缺少合法销毁途径）

### 8.3 物理层如何重新定义「配方」

传统游戏中，"配方"是：
```
配方 = 输入物品列表 → 输出物品列表
```

ONI 中，"配方" = 物质转化 + **隐含的物理约束集合**：

```
配方 = {
  输入物质: [{ 类型, 质量, 温度范围, 物质形态(固/液/气) }],
  转化条件: { 电力, 劳动, 温度, 气压, 光照, 辐射(Spaced Out!) },
  输出物质: [{ 类型, 质量, 固定温度, 物质形态 }],
  隐含产出: { 废热, 病菌, 辐射, 噪声 },
  环境约束: { 气体环境要求, 淹没限制, 地基要求 },
  失败模式: { 管道破裂(相变), 设备过热, 气压失衡, 生物死亡 }
}
```

**关键转变**：
- Factorio 的配方失败 → "材料不够"（唯一的失败模式）
- ONI 的配方可以因 5 种以上不同的物理原因失败，且失败是**级联性的**（一个设备过热 → 周围气体升温 → 作物枯萎 → 氧气中断 → 复制人死亡）

### 8.4 对工业模拟游戏设计的启示

ONI 证明了一个核心理念：

> **"配方"不需要显式定义——如果底层物理模拟足够丰富，配方可以从物理规则中涌现出来。**

对于想要设计类似系统的游戏：

1. **赋予每个"配方"一个物理签名**（温度、相态、副产物）
2. **让失败模式多样化**——不仅是缺货，还有过热、污染、扩散
3. **保证每个输出有多个处理路径**——没有"正确答案"
4. **让物理规则能被玩家利用**（热交换逆流、重力分层）——不要只让物理成为阻碍
5. **固定输出温度是一个简单但极有效的设计**——它创造了不对称性，不对称性 = 有趣的决策

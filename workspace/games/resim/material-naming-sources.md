# 物质命名来源参考

> 状态：**讨论阶段**
> 日期：2026-07-04
> 标签：`game-design` `materials` `naming` `reference-data`

本文件讨论游戏中"物质"（Material）的命名来源与分类体系。它是 [工业化模拟游戏设计讨论](industrial-simulation-game-design.md) 的配套文档。

---

## 一、命名体系总览

游戏中每种物质需要承载三层名称：

```
以硫酸为例：

系统 ID（内部唯一标识）：
  sulfuric_acid_conc_98pct
  → 严格唯一，机器可读，配方匹配和数据引用的 key

学名 / 正式名（UI 显示，知识型玩家可见）：
  "浓硫酸 (H₂SO₄, ~98%)"
  → 化学式 + 浓度，精确但可能不够友好

俗名 / 历史名（轻度玩家、提示系统、NPC 对话）：
  "绿矾油" "镪水" "vitriol oil" "oil of vitriol"
  → 有历史/叙事沉浸感，知识系统发现阶段的提示文本用此层
```

不同来源各司其职：有的提供唯一标识（CAS 号），有的提供分类层级（HS 编码），有的提供历史沉浸（《天工开物》），有的提供权威属性数据（Mindat）。

按物质类别的整体对应关系：

| 物质类别 | 主来源 | ID 锚点 | 别名来源 | MVP 数量 |
|----------|--------|---------|----------|----------|
| 化学元素 | IUPAC 周期表 | 原子序数 | 古代名称（金银铜铁锡铅汞硫……） | ~20 |
| 简单化合物 | CAS + PubChem | CAS RN | 古代名称 + 工业俗名 | ~50 |
| 矿物 | IMA + Mindat | IMA 编号 | 古代/本地名称 | ~30 |
| 合金 | UNS | UNS 编号 | 俗名（黄铜、青铜、白铜……） | ~15 |
| 大宗商品 | HS 编码 | HS 6 位码 | - | ~30 |
| 燃料 | ASTM D388 + API | ASTM 等级 | 地方俗名 | ~10 |
| 工业副产物 / 废物 | EWC + 工业生态学文献 | EWC 代码 | - | ~15 |
| 加工零件 | HS + 工程标准 | 自定 ID | - | ~10 |

**互操作规则**：
1. 每种物质的 `ref` 字段记录来源引用（CAS / IMA / HS / UNS / EWC / …），方便查证
2. 如果一种物质可被多种来源定义（如硫酸既是商品 HS 2807 又是化学品 CAS 7664-93-9），**以 CAS 为主**——化学式是第一性原理
3. HS 编码主要用于"加工商品"层级——那些没有化学式的工业品（齿轮、线缆、水泥）
4. `tags` 字段独立于来源，由游戏设计者定义。两个不同来源的物质可以有相同的游戏标签

## 二、纯化学物质：CAS Registry + PubChem

### 2.1 CAS Registry Number

**CAS（Chemical Abstracts Service）** 是全球最权威的化学物质登记系统，收录约 **2 亿种** 物质。每个物质分配一个唯一的 CAS Registry Number（CAS RN），格式为 `NNNNNN-NN-N`（如硫酸 = `7664-93-9`）。

**在游戏中的角色**：
- 作为**权威锚点**。当不确定"这个物质到底是什么"时，CAS 号是最终裁决者。
- mod 作者添加新物质时，提供 CAS 号可防止 ID 冲突。
- CAS 号本身没有化学语义（你无法从 `7664-93-9` 推导出它是 H₂SO₄），但它的唯一性无争议。

**局限性**：
- CAS 是商业机构的数据库（属美国化学会），部分服务需要授权
- CAS RN 不传递任何化学结构信息（不像 InChIKey 或 SMILES）

### 2.2 PubChem

**PubChem** 是 NIH（美国国立卫生研究院）维护的开放数据库，收录约 **1.1 亿种** 化合物。

**关键价值——同义词库**：
每种化合物在 PubChem 中有几十到几百个同义词。以硫酸为例：
- 系统名：`sulfuric acid`
- 同义词：`oil of vitriol`, `battery acid`, `hydrogen sulfate`, `dihydrogen sulfate`, `vitriol brown oil`, `Schwefelsäure`, `acide sulfurique`, `7664-93-9`, ...
- 注册号：CAS、EC、UNII、ChEBI、KEGG、RTECS、……

游戏可以直接使用 PubChem 的同义词列表作为三层名称中的"俗名/历史名"字段。一个 `GET` API 调用即可拿到完整列表，不需要手动收集。

**其他标识符（PubChem 同时提供）**：

| 标识符 | 说明 | 对游戏的价值 |
|--------|------|------------|
| **InChI / InChIKey** | 结构编码字符串，从结构唯一推导 | 自动验证"两个 ID 是否同一物质" |
| **SMILES** | 线式结构符号，如 `OS(=O)(=O)O` | 可用于程序化生成化学式的 UI 显示 |
| **分子式** | H₂SO₄ | UI 显示 |
| **分子量** | 98.079 g/mol | 配方比例计算 |

**务实做法**：
- MVP 阶段手动挑选 ~50 种核心化学物质，从 PubChem 复制 CAS + 同义词 + 分子式
- 未来可通过 PubChem 的 REST API（`pubchem.ncbi.nlm.nih.gov/rest/pug`）做自动化查询
- `ref` 字段记录 CAS RN 为主，同时可附带 PubChem CID

## 三、矿物：IMA + Mindat + Strunz 分类

### 3.1 IMA（国际矿物学协会）

IMA 的 **CNMNC（新矿物、命名和分类委员会）** 维护官方认可矿物种类列表，目前约 **6000 种**。每种矿物有唯一 IMA 编号和标准化学式。

**"铜矿"应该拆成多少种？IMA 列表就是权威答案**：

| IMA 矿物 | 化学式 | 铜含量 | 矿物大类 |
|----------|--------|--------|----------|
| 自然铜（Copper） | Cu | ~100% | 自然元素 |
| 黄铜矿（Chalcopyrite） | CuFeS₂ | ~34.6% Cu | 硫化物 |
| 斑铜矿（Bornite） | Cu₅FeS₄ | ~63.3% Cu | 硫化物 |
| 辉铜矿（Chalcocite） | Cu₂S | ~79.8% Cu | 硫化物 |
| 铜蓝（Covellite） | CuS | ~66.5% Cu | 硫化物 |
| 黝铜矿（Tetrahedrite） | Cu₁₂Sb₄S₁₃ | ~45.8% Cu | 硫盐 |
| 赤铜矿（Cuprite） | Cu₂O | ~88.8% Cu | 氧化物 |
| 黑铜矿（Tenorite） | CuO | ~79.9% Cu | 氧化物 |
| 孔雀石（Malachite） | Cu₂CO₃(OH)₂ | ~57.5% Cu | 碳酸盐 |
| 蓝铜矿（Azurite） | Cu₃(CO₃)₂(OH)₂ | ~55.3% Cu | 碳酸盐 |
| 硅孔雀石（Chrysocolla） | (Cu,Al)₂H₂Si₂O₅(OH)₄·nH₂O | 不定 | 硅酸盐 |
| 氯铜矿（Atacamite） | Cu₂Cl(OH)₃ | ~59.5% Cu | 卤化物 |

游戏中孔雀石（碳酸盐）、黄铜矿（硫化物）和自然铜（自然元素）的处理方式完全不同——这恰好是 IMA 三大类（碳酸盐→可酸浸、硫化物→需焙烧、自然元素→直接锻打）。

### 3.2 Mindat.org

**Mindat** 是全球最大的矿物学数据库，约 **5.5 万条目**（包含变种和非正式名称）。

**Mindat 独有的关键数据**：

1. **伴生关系**（Associated Minerals）：
   ```
   黄铜矿 "commonly associated with pyrite, galena, sphalerite, bornite"
   
   → 游戏中：开采"黄铜矿"矿脉时，同时产出黄铁矿、方铅矿、闪锌矿
   → 不只是一个矿石 -> 一个金属，而是一个矿脉 -> 多种矿物 -> 多种金属
   ```

2. **物理性质**：硬度（Mohs）、比重、颜色、条痕颜色、解理、断口……这些天然适用于知识系统的渐进发现：
   - L1："这是一种黄铜色的、有金属光泽的矿物，硬度约 3.5-4"
   - 玩家（如果知道黄铜矿特征）→ 直接识别
   - 否则 → 系统逐步缩小范围，最终在 L3 给出名称

3. **产地信息**：每种矿物在全球的产地——可以用来生成游戏地图的"区域特色"

### 3.3 Strunz 分类（推荐）vs Dana 分类（已过时）

**Nickel–Strunz 分类**（第 10 版）使用层级编码 `NN.XY.##x`：

```
Strunz 分类层级示例：

01 自然元素
  01.AA 铜族
    01.AA.05 自然铜（Copper）

02 硫化物和硫盐
  02.CB 黄铜矿族（M:S=1:1）
    02.CB.10a 黄铜矿（Chalcopyrite）CuFeS₂
    02.CB.10b 方黄铜矿（Cubanite）CuFe₂S₃
  02.BA 辉铜矿族（M:S>1:1）
    02.BA.05a 辉铜矿（Chalcocite）Cu₂S
  02.CA 铜蓝族（M:S=1:1）
    02.CA.05a 铜蓝（Covellite）CuS

04 氧化物
  04.AA 赤铜矿族
    04.AA.10 赤铜矿（Cuprite）Cu₂O

05 碳酸盐
  05.BA 孔雀石族
    05.BA.10 孔雀石（Malachite）Cu₂CO₃(OH)₂
    05.BA.05 蓝铜矿（Azurite）Cu₃(CO₃)₂(OH)₂
```

**Strunz 编码天然适合作为游戏中的标签层级**：
```
tag: strunz_class_02  → 所有硫化物，需要焙烧脱硫
tag: strunz_class_04  → 所有氧化物，可直接酸浸
tag: strunz_class_05  → 所有碳酸盐，可加热分解
tag: strunz_class_01  → 自然元素，可直接锻打
```

玩家识别出矿物大类（通过提示系统），就能推断可行处理路线——这是知识系统渐进发现的完美载体。

**Dana 分类**（第 8 版，1997 年最后更新，仅覆盖 3700 种矿物）已被 Mindat 于 2021 年停止维护。**推荐使用 Strunz 作为矿物的游戏内分类标签**。

### 3.4 务实做法

- MVP 阶段只需 ~30 种矿物，覆盖铜/铁/锡/铅/锌/金银的 2-3 种代表矿物
- 手动从 Mindat/I MA 挑选，以 IMA 名称 + Strunz 编码为基准
- `ref` 字段记录 IMA 编号
- `tags` 字段包含 Strunz 大类标签（`strunz_02_sulfide` / `strunz_04_oxide` / `strunz_05_carbonate` / …）
- `associated_minerals` 字段从 Mindat 伴生关系复制

## 四、工业商品 / 大宗物资：HS 编码 + SITC

### 4.1 HS 编码（商品名称及编码协调制度）

世界海关组织（WCO）维护的 6 位编码体系。全球约 **5000 个** 6 位子目。

**HS 编码的层级结构恰好匹配游戏的工业链**：

```
Section V（第25-27章）矿产品
  第26章  矿砂、矿渣及矿灰
    2603   铜矿砂及其精矿
    2601   铁矿砂及其精矿
      2601.11 铁矿砂，未烧结（粉矿）
      2601.12 铁矿砂，已烧结（球团/烧结矿）

Section VI（第28-38章）化学及相关工业产品
  第28章  无机化学品
    2807   硫酸；发烟硫酸
    2827   氯化物（含 NH₄Cl — 侯氏制碱法副产物）
    2836   碳酸盐（含纯碱 Na₂CO₃）

Section XV（第72-83章）贱金属及其制品
  第74章  铜及其制品
    7401   铜锍；沉淀铜（cement copper = 铁置换海绵铜！）
    7402   未精炼铜；电解精炼用铜阳极
    7403   精炼铜及铜合金（阴极铜、线锭、铜合金）
    7404   铜废料及碎料
    7408   铜线（精炼铜制）
    7411   铜管
```

**HS 层级 → 游戏中的抽象层级**：

```
第26章（原材料矿砂）     → 地图上的采集/采矿建筑
第28章（无机化学品）     → 中间产品，工业链节点
第74章（铜制品）        → 终端产品，可交易/使用的商品
```

地图层的"铜冶炼厂"蓝图——输出可以是 `HS 7403`（精炼铜，抽象为铜锭），展开蓝图后才是具体的电解槽和铜阴极。

### 4.2 SITC（国际贸易标准分类）

联合国体系，按加工程度分组，**比 HS 更适合验证工业链的阶段划分**：

```
SITC 68（有色金属）：
  682  铜
    6821  未精炼铜（粗铜/冰铜/沉淀铜）
      68211 粗铜（blister copper）
      68212 铜锍（copper matte）
      68213 沉淀铜（cement copper）
    6822  精炼铜（未锻轧）
      68221 铜阴极
      68222 铜线锭
      68223 铜坯
    6823  铜材（已锻轧）
      68231 铜棒/型材
      68232 铜线
      68233 铜板/带
      68234 铜箔
```

SITC 从 `原材料（6821）→ 未锻轧（6822）→ 已锻轧（6823）` 的层级天然对应游戏的工业化三阶段。**设计工业链时可以对照 SITC 检查是否遗漏了中间产品**。

### 4.3 UN Comtrade

HS 编码对应的真实贸易数据——可参考价格比（铜矿石 vs 精炼铜的比例大致多少），用于经济系统的初始调参。不是命名来源但可用于平衡性参考。

## 五、金属与合金：UNS + 各国材料标准

### 5.1 UNS（统一编号系统）

UNS 覆盖约 **5000 种** 金属和合金：

| 前缀 | 材料类别 | 编号范围 |
|------|---------|----------|
| **C** | 铜及铜合金 | C10000–C99999 |
| **S** | 不锈钢 | S00001–S99999 |
| **A** | 铝合金 | A00001–A99999 |
| **G** | 碳钢及合金钢 | G00001–G99999 |
| **T** | 钛 | T00001–T99999 |
| **N** | 镍及镍合金 | N00001–N99999 |
| **Z** | 锌及锌合金 | Z00001–Z99999 |
| **L** | 铅及铅合金 | L00001–L99999 |

**铜合金的 UNS 细分**：

```
C10100 – C13000  纯铜（≥99.3% Cu）
  C11000 = 电解韧铜（ETP），Cu 99.90%，最常用的导电铜
  C10200 = 无氧铜（OF），Cu 99.95%
  C12200 = 磷脱氧铜（DHP），Cu 99.90% + P 0.015-0.040%

C21000 – C28000  铜锌合金（黄铜）
  C26000 = 弹壳黄铜（Cu 70%, Zn 30%）
  C28000 = 蒙次黄铜（Cu 60%, Zn 40%）

C50000 – C53000  铜锡合金（磷青铜）
  C51000 = 磷青铜 5%A（Cu 95%, Sn 5%）

C60600 – C64400  铜铝合金（铝青铜）
C70000 – C73000  铜镍合金（白铜）
```

在游戏中，合金的物质定义方式应当是 `composition: { Cu: 0.70, Zn: 0.30 }` + 标签 `tags: [brass, alpha_brass, ...]`。UNS 编号作为 `ref` 字段。

### 5.2 AISI/SAE 钢号 + 国标（GB/T）

**AISI/SAE 钢号** 携带成分信息：
- `1040` = 含碳 0.40% 的碳钢
- `4140` = Cr-Mo 合金钢（1% Cr, 0.2% Mo）
- `316` = 奥氏体不锈钢（含 Cr 18%, Ni 10%, Mo 2%）

**中国国标** 对本土玩家更友好：
- `Q235`（碳素结构钢，最普通的钢）
- `45号钢`（含碳 0.45%）
- `304` 不锈钢（06Cr19Ni10）

**务实做法**：
- 游戏中只区分大类：熟铁（C<0.03%）/ 低碳钢 / 中碳钢 / 高碳钢 / 铸铁（C>2%）/ 不锈钢
- 每种大类对应一种物质 ID，附加 `carbon_content` 标签
- UNS/国标标号作为 `ref` 参考

## 六、燃料：ASTM D388（煤）+ API 重度（石油）

### 6.1 ASTM D388 煤炭分类

按**煤化程度**（rank）将煤分为四大类：

```
无烟煤类（Anthracitic）：
  meta-anthracite   固定碳 ≥98%, 挥发分 ≤2%
  anthracite         固定碳 92-98%, 挥发分 2-8%
  semianthracite     固定碳 86-92%, 挥发分 8-14%

烟煤类（Bituminous）：
  low volatile       固定碳 78-86%, 挥发分 14-22%
  medium volatile    固定碳 69-78%, 挥发分 22-31%
  high volatile A    发热量 ≥14,000 Btu/lb (~32.6 MJ/kg)
  high volatile B    发热量 13,000-14,000 Btu/lb
  high volatile C    发热量 10,500-13,000 Btu/lb（有黏结性）

次烟煤类（Subbituminous）：
  Subbituminous A    发热量 10,500-11,500 Btu/lb
  Subbituminous B    发热量 9,500-10,500 Btu/lb
  Subbituminous C    发热量 8,300-9,500 Btu/lb

褐煤类（Lignitic）：
  Lignite A          发热量 6,300-8,300 Btu/lb
  Lignite B          发热量 <6,300 Btu/lb
```

**游戏中的煤物质定义**：

```yaml
coal_anthracite:
  name: "无烟煤"
  ref: "ASTM D388: anthracite"
  composition:
    fixed_carbon: 0.92
    volatile_matter: 0.05
    ash: 0.02
    sulfur: 0.01
    moisture: 0.01
  combustion_enthalpy: 32_MJ/kg    # ~13,700 Btu/lb
  tags: [combustible, fossil_fuel, low_smoke, high_rank_coal]

coal_bituminous_hv:
  name: "烟煤（高挥发分）"
  ref: "ASTM D388: high volatile A bituminous"
  composition:
    fixed_carbon: 0.60
    volatile_matter: 0.30
    ash: 0.06
    sulfur: 0.03
    moisture: 0.03
  combustion_enthalpy: 25_MJ/kg    # ~10,700 Btu/lb
  tags: [combustible, fossil_fuel, caking, moderate_smoke]

coal_lignite:
  name: "褐煤"
  ref: "ASTM D388: lignite A"
  composition:
    fixed_carbon: 0.35
    volatile_matter: 0.25
    ash: 0.10
    sulfur: 0.02
    moisture: 0.30
  combustion_enthalpy: 15_MJ/kg    # ~6,400 Btu/lb
  tags: [combustible, fossil_fuel, smoky, low_rank_coal]
```

**游戏意义**：
- `combustion_enthalpy` 决定热量产出
- `ash` 决定固体废物量（炉渣处理压力）
- `sulfur` 决定 SO₂ 排放（污染或需要脱硫设备→副产硫酸）
- `volatile_matter` 决定燃烧特性（烟煤适合炼焦→焦炭→高炉）
- `caking` 标签决定是否可用于炼焦

### 6.2 API 重度（石油分类）

| 分类 | API Gravity | 特点 |
|------|------------|------|
| 轻质原油（Light） | >31.1° | 汽油/石脑油产率高 |
| 中质原油（Medium） | 22.3–31.1° | 均衡 |
| 重质原油（Heavy） | 10.0–22.3° | 润滑油/沥青产率高 |
| 超重原油（Extra Heavy） | <10.0° | 几乎为固态沥青 |

不同 API 重度在游戏中的蒸馏塔蓝图里决定产物分布，通过 `api_gravity` 标签控制。

### 6.3 其他燃料分类来源

| 燃料类型 | 分类标准 | 关键参数 |
|----------|---------|----------|
| 生物质（木屑颗粒） | ENplus | 灰分 <0.7%, 水分 <10%, 热值 >16.5 MJ/kg |
| 天然气 | ISO 6976 | 热值、甲烷含量、硫含量 |
| 焦炭 | ASTM D4715 | 固定碳、灰分、硫、反应性 |

**务实做法**：第一版 ~10 种燃料：3-4 种煤（无烟煤+1-2种烟煤+褐煤+泥炭）+ 木炭 + 焦炭 + 生物质 + 重油（预留）。属性参考 ASTM/API 数据。

## 七、工业副产物 / 废物：EWC + 工业生态学文献

这是最容易被忽视但游戏中**最关键**的物质类别。副产物不是"消失的废物"——它们驱动了废物处理、资源回收、环境风险的玩法。

### 7.1 EWC（欧洲废物名录）

EWC 按**产生来源**分类，而非化学成分。第 10 章和第 11 章与游戏直接相关：

**第 10 章——热过程废物（炉渣、飞灰）**：

```
10 01 01  底灰、炉渣、锅炉灰（发电站）              非危险
10 01 02  煤飞灰（coal fly ash）                   非危险
10 01 04* 油飞灰                                   危险
10 02 01  炉渣处理废物（钢铁）                      非危险
10 02 02  未处理炉渣（钢铁）                        非危险
10 06 01  炉渣（铜冶炼，一次和二次生产）            非危险
10 07 01  炉渣（金银铂冶炼）                        非危险
```

**铜冶炼炉渣（10 06 01）** 在游戏中的定义：
```yaml
slag_copper_smelting:
  name: "铜冶炼炉渣"
  ref: "EWC 10 06 01"
  composition:
    FeO: 0.40
    SiO2: 0.35
    CaO: 0.10
    Al2O3: 0.08
    residual_Cu: 0.01       # 仍含 1% 的铜！后续可回收
    other_metals: 0.06      # 微量 Zn, Pb, As...
  tags: [slag, waste, non_hazardous, construction_material]
```

**第 11 章——非铁金属湿法冶金废物（阳极泥、电解液）**：

```
11 02 03  电解水溶液过程阳极生产废物                非危险
11 02 05* 铜湿法冶金废物（含危险物质）              危险（镜像条目）
11 02 06  铜湿法冶金废物（不含危险物质）            非危险（镜像条目）
11 02 02* 锌湿法冶金污泥（含黄钾铁矾等）            危险
```

**阳极泥** 没有独立 EWC 代码（它被归入 11 02 05*/11 02 06 的铜湿法冶金类别），但它是游戏中最重要的副产物之一：

```yaml
anode_slime_copper_electrorefining:
  name: "铜电解阳极泥"
  ref: "EWC 11 02 05* / 11 02 06（取决于成分）"
  composition:
    Cu: 0.18
    Ag: 0.05
    Au: 0.01
    Se: 0.08
    Te: 0.03
    Pb: 0.10
    As: 0.02
    Sb: 0.03
    other: 0.50
  tags: [waste, anode_slime, precious_metal_bearing, hazardous_possible]
```

让玩家从阳极泥中回收金银硒碲——这不是开发者"设计"的玩法，而是真实冶金副产物本身就含这些元素。数据来源是工业冶金文献。

### 7.2 其他来源

| 来源 | 覆盖范围 | 对游戏的价值 |
|------|---------|------------|
| **Ecoinvent 数据库** | 数千个工业过程的 LCA 数据，包含输入输出全貌 | 每个工艺步骤的完整物料平衡 |
| **USGS 矿物年鉴** | 全球矿产品产量与回收率 | 采矿→选矿→冶炼→加工各环节的收率数据 |
| **中国《国家危险废物名录》** | HW 代码体系，数百种危险废物 | 含铜废物（HW22）、含锌废物（HW23）、废酸（HW34）、废碱（HW35）… |
| **工业生态学文献** | 物质流分析（MFA）、共生系统案例 | 跨工艺的副产物耦合机会 |

### 7.3 副产物在游戏中的角色

- EWC 代码提供了副产物的 **"身份证"**——让废物也有唯一的、可查找的标识
- 镜像条目（如 11 02 05* vs 11 02 06）天然提示了**副产物可能有危险/安全两种状态**，取决于工艺参数
- 副产物的 `composition` 字段让"废物→资源"的转化有数据支撑——不是凭空设计，而是真实工业的反映

## 八、古代/历史名称：《天工开物》等文献

### 8.1 《天工开物》——中国明代工业术语

《天工开物》（宋应星，1637 年）是记录 17 世纪中国工业技术的百科全书。卷十四《五金》记录了金属与矿物的古代称谓：

**金属名称**：

| 古代名称 | 现代对应 | 说明 |
|---------|---------|------|
| **倭铅** | **锌（Zn）** | "以其似铅而性猛，故名倭铅"。由炉甘石（菱锌矿）蒸馏制得。世界上最早的火法炼锌记载 |
| 赤铜 | 纯铜 / 红铜 | 铜的原始形态 |
| 黄铜 | Cu-Zn 合金 | 赤铜 + 倭铅共熔 |
| 白铜 | Cu-Ni 合金 | 赤铜 + 砒霜等药炼制 |
| 青铜 | Cu-Sn 合金 | 赤铜 + 矾硝等炼制 |
| 响铜 | Cu-Sn 合金 | 制乐器专用（广锡比例高） |
| 生铁 | 铸铁（C>2%） | 未经过炒炼 |
| 熟铁 | 锻铁（C<0.03%） | 生铁经炒炼脱碳 |
| 钢 | 钢 | "生熟相和"（灌钢法） |

**矿物名称**：

| 古代名称 | 现代对应 |
|---------|---------|
| 炉甘石 | 菱锌矿（ZnCO₃） |
| 铜璞 / 铜砂 | 铜矿石 |
| 自然铜 / 石髓铅 | 自然铜（Native Copper） |
| 慈石 | 磁铁矿（Fe₃O₄） |
| 礁砂 | 银矿石 |

**冶金操作术语**：

| 古代术语 | 现代含义 |
|---------|---------|
| 升炼 | 蒸馏法冶炼（用于锌、汞等低沸点金属） |
| 鼓鞲 | 鼓风（用风箱） |
| 固济 | 密封（泥封罐口） |
| 煎炼 | 火法冶炼 |
| 分金炉（虾蟆炉） | 金银分离炉 |
| 点 | 加入少量物质引发反应 |
| 淬 | 将烧红金属浸入液体冷却 |

### 8.2 其他中国文献

| 文献 | 年代 | 贡献 |
|------|------|------|
| 《神农本草经》 | 汉（约 200 CE） | 最早的矿物药分类：**绿矾**（FeSO₄·7H₂O）、**白矾**（KAl(SO₄)₂·12H₂O）、**石硫黄**（硫磺）、**朴硝**（Na₂SO₄·10H₂O） |
| 《本草纲目》（李时珍） | 明（1578） | 扩展收录大量矿物药：**石胆**（胆矾 CuSO₄·5H₂O）、**曾青**（蓝铜矿）、**空青**（孔雀石）、**粉锡**（胡粉/铅白） |
| 《熬波图》（陈椿） | 元（1334） | 制盐技术专著 |
| 《滇南矿厂图略》 | 清 | 云南铜矿开采冶炼详细记录 |

### 8.3 欧洲/伊斯兰文献

| 文献 | 年代 | 贡献 |
|------|------|------|
| 老普林尼《自然史》 | 罗马（77 CE） | 记录矿物、金属、染料。**vitriol**（硫酸盐类）、**chrysocolla**（硅孔雀石→铜焊料） |
| 贾比尔·伊本·哈扬（Geber）著作 | 8 世纪 | 记录蒸馏、结晶、升华。**aqua regia**（王水）、**aqua fortis**（硝酸）。阿拉伯语词汇至今残留：**alcohol**、**alkali**、**alembic** |
| 阿格里科拉《论矿冶》（De Re Metallica） | 1556 | 系统性矿物学/冶金学。大量拉丁语→德语矿物术语，至今是矿物学基础 |

### 8.4 历史名称在游戏中的角色

```yaml
sulfuric_acid:
  id: sulfuric_acid_conc_98pct
  name_display: "浓硫酸 (H₂SO₄, ~98%)"
  historical_names:
    chinese: ["绿矾油", "镪水"]
    latin: ["oleum vitrioli"]
    english: ["oil of vitriol", "vitriol brown oil"]
    arabic: ["zāj"]
  ref: "CAS 7664-93-9"
```

历史名称用于三层命名体系的"俗名/历史名"层：
- NPC 对话用历史名称（"铁匠递给你一罐绿矾油"）
- 提示系统 L0-L2 阶段用历史/感官描述
- L3 才给出学名——"绿矾油，即硫酸"
- 有知识的玩家（穿越者）听到"绿矾油"就懂了——**穿越者红利**

## 九、Wikidata 作为统一的元数据层（长期愿景）

### 9.1 为什么是 Wikidata

上述所有来源——CAS、PubChem、IMA、Strunz、HS、UNS——在 Wikidata 中都有对应的 Q-item 和属性（Property）。

| 数据 | Wikidata 属性 | 说明 |
|------|-------------|------|
| CAS 号 | `P231` | 化学物质 ~87% 覆盖 |
| PubChem CID | `P662` | ~19% 覆盖 |
| InChIKey | `P235` | ~94% 覆盖，可用于自动匹配 |
| 化学式 | `P274` | 几乎所有化学物质 |
| IMA 编号 | `P484` | 所有认可矿物 |
| Strunz 编码 | `P711`/`P712`/`P713` | 3 个版本（第 8/9/10 版） |
| Dana 编码 | `P714` | 第 8 版 |
| 莫氏硬度 | `P1088` | 大部分矿物 |
| 晶体结构 | `P556` | 矿物分类信息 |

### 9.2 理想场景

游戏的物质数据文件引用 Wikidata Q-ID：

```yaml
sulfuric_acid:
  wikidata: Q4118
  # 可从 Q4118 自动拉取：
  # - CAS: 7664-93-9
  # - PubChem CID: 1118
  # - 化学式: H2SO4
  # - 所有语言的别名: "sulfuric acid", "Schwefelsäure", "硫酸", ...
  game_tags: [acid, strong_acid, corrosive, dehydrating, oxidizing]
  composition: { H2SO4: 0.98, H2O: 0.02 }

chalcopyrite:
  wikidata: Q109189
  # 自动获取：
  # - IMA 编号
  # - Strunz 02.CB.10a
  # - 化学式: CuFeS2
  # - 伴生矿物（Mindat 交叉引用）
  game_tags: [copper_ore, sulfide, primary_copper_source]
```

**这意味着**：
- 基础数据层（化学式、别名、分类）由 Wikidata 社区维护
- 游戏只维护**游戏特有数据**（标签、平衡数值、默认工艺路线）
- mod 作者添加新物质：只需 `wikidata: Qxxxx` + `game_tags`，基础属性自动获取

### 9.3 当前务实立场

MVP 阶段手动填写 ~150 种物质的数据完全可行。Wikidata 引用是"有余力就做"的长期方向。在数据模型层面，预留 `wikidata` 字段即可。

## 十、来源优先级总结

```
纯化学物质（CAS + PubChem）
  │
  ├─ 矿物（IMA + Strunz）──── 按 Dana 大类标注 behavior 标签
  │
  ├─ 合金（UNS + 国标）──── 按 UNS 前缀分类（C/S/G/A/…）
  │
  ├─ 大宗商品（HS 编码）──── 按 HS 层级分原材料/中间品/制成品
  │     └─ 加工零件（HS + 工程标准）──── 没有化学式的工业品
  │
  ├─ 燃料（ASTM D388 + API）──── 决定燃烧行为的关键属性
  │
  ├─ 废物/副产物（EWC + 工业生态学）──── 驱动废物管理玩法
  │
  └─ 历史名称（天工开物 + 炼金文献）──── 作为 historical_names，供 UI 和提示系统
```

**每种来源对应一个游戏系统，而不仅仅是名字的来源**：
- CAS/PubChem → 规则引擎的化学式→反应式匹配
- IMA/Strunz → 矿物分类→知识系统的渐进鉴定→工艺路线选择
- HS/SITC → 工业链阶段验证→经济系统定价参考
- UNS → 合金成分配方
- ASTM D388 → 燃料燃烧行为（热值/灰分/硫→污染→副产）
- EWC → 副产物追踪和"废物→资源"转化
- 《天工开物》等 → 提示系统 + NPC 对话 + 穿越者红利的沉浸层

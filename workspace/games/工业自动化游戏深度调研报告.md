# 工业自动化游戏深度调研报告

> 调研范围：15 款代表性工业自动化/工厂建造游戏，涵盖 S/A/B 三个梯队。
> 调研日期：2026-07-04
> 语言：中文（zh-Hans）

---

## 一、总体分类与定位

### 1.1 自动化纯度光谱

工业自动化游戏并非铁板一块。按照"自动化作为核心玩法"的纯度，15 款游戏分布在如下光谱上：

```
纯自动化解谜 ←————————————————————————————→ 自动化作为辅助系统

Shapez      Factorio  DSP   Satisfactory  CoI    ONI   Mindustry  Riftbreaker  Planet Crafter
Infinifactory           Cosmoteer        Railgrade    Astroneer   Plan B
```

| 游戏 | 自动化纯度 | 说明 |
|------|:--:|------|
| **Shapez / Infinifactory** | ★★★★★ | 纯粹的自动化/物流解谜，剥离所有生存要素 |
| **Factorio** | ★★★★★ | 自动化是目的本身，战斗为自动化服务 |
| **Dyson Sphere Program** | ★★★★☆ | 自动化是核心，但星际探索和视觉奇观权重较高 |
| **Satisfactory** | ★★★★☆ | 自动化是核心，但探索、建筑美学权重高 |
| **Captain of Industry** | ★★★★☆ | 自动化+生存管理+地形改造三重核心 |
| **Mindustry** | ★★★☆☆ | 自动化服务于塔防/RTS，战斗与建造并重 |
| **Cosmoteer** | ★★★☆☆ | 船员物流优化近似自动化，战斗为核心输出 |
| **Railgrade** | ★★★☆☆ | 火车物流解谜，关卡制约束取代沙盒自由 |
| **Oxygen Not Included** | ★★★☆☆ | 生存模拟为主，自动化是后期高级工具 |
| **Astroneer** | ★★☆☆☆ | 探索+手工建造，自动化极为浅层 |
| **The Riftbreaker** | ★★☆☆☆ | 塔防+ARPG，基地建造有基础自动化 |
| **Assembly Line** | ★★★☆☆ | 纯解谜型自动化，但深度和体量受限 |
| **Plan B: Terraform** | ★★☆☆☆ | 星球改造为主，物流极度简化 |
| **The Planet Crafter** | ★☆☆☆☆ | 生存建造，自动化是极后期减负手段 |

### 1.2 视角维度

| 视角类型 | 游戏 |
|----------|------|
| **2D 俯视/侧视** | Factorio, Mindustry, Shapez 1, Assembly Line, Railgrade (3D 棋盘) |
| **2.5D 等距/3D 俯视** | Captain of Industry, Plan B: Terraform, Cosmoteer, Infinifactory (第一人称体素) |
| **3D 第一人称** | Satisfactory, Astroneer, The Riftbreaker, The Planet Crafter |
| **3D 第三人称/混合** | Dyson Sphere Program (机甲操控+上帝视角), Shapez 2 (自由相机 3D), Oxygen Not Included (横切面 2D) |

**关键洞见**：视角选择不是美学偏好，而是**根本性地决定**了游戏的建造范式：

- **2D 俯视**游戏天然适合"上帝视角下的系统设计"——玩家看到的是数据流和逻辑拓扑，工厂被抽象为节点和边。
- **3D 第一人称**游戏将建造行为本身变为物理空间导航——玩家"居住"在工厂中，美观从可选变为核心需求。
- **2D 横切面**（ONI）是独特的第三范式——垂直分层的流体物理模拟，在 2D 网格中实现准 3D 的物质行为。

### 1.3 开放世界 vs 关卡制

| 结构 | 游戏 | 特点 |
|------|------|------|
| **完全开放世界（程序生成）** | Factorio, Mindustry (战役外) | 无限重玩性，每次体验不同 |
| **完全开放世界（手工地图）** | Satisfactory, Astroneer, ONI, CoI, DSP, Riftbreaker, Planet Crafter | 探索可学习，但重玩性受限 |
| **关卡制+沙盒** | Shapez, Plan B, Cosmoteer | 主线有结构，沙盒无限 |
| **纯关卡制** | Infinifactory, Railgrade | 每关是独立谜题，无持久世界 |
| **混合** | Assembly Line (无限扩展的网格) | 单屏幕内的开放式优化 |

### 1.4 目标受众矩阵

```
                    硬核深度
                      │
          Factorio    │
          ONI         │  Captain of Industry
          Mindustry   │
                      │
 纯自动化 ────────────┼──────────── 自动化+战斗/生存
                      │
 Shapez    DSP        │  Riftbreaker
 Infinifactory        │  Cosmoteer
 Satisfactory         │
                      │  Planet Crafter
          Astroneer   │  Plan B
          Railgrade   │
                      │
                    休闲轻度
```

**核心受众重合度认知**：Factorio 玩家是品类的"圆心"——几乎所有其他游戏的受众都与 Factorio 玩家有不同程度的重叠。但 Satisfactory 和 DSP 各自吸引了不同的"离心"群体：前者吸引建筑美学和探索爱好者，后者吸引视觉奇观和星际叙事爱好者。

## 二、S 级游戏深度分析

### 2.1 异星工厂（Factorio）

#### 2.1.1 核心玩法循环

```
开采原始资源 → 组合成复杂物品 → 整合进工厂 → 研究下一级科技 → 循环
        ↑                                            ↓
        └──────── 解锁新工具/武器/物流 ───────────────┘
```

这是品类中最纯粹的**递归式自指循环**——自动化解决的每一个问题都会创造十个新问题，新问题需要更复杂的自动化来解决。游戏被社区称为"软件工程模拟器"并非巧合：**抽象化、模块化、重构、技术债务**这些软件工程概念在 Factorio 的工厂中有物理可见的对应物。

#### 2.1.2 系统深度

**生产系统**——配方图是骨架。每种物品有明确的工艺时间、输入数量和输出数量。组装机有固定速度系数（Assembling Machine 1: 0.5x → AM3: 1.25x）。Space Age DLC 新增的四种星球专属建筑（铸造厂、电磁工厂、生物室、低温工厂）各带 50% 基础生产力，**改变了"在哪里建造什么"的战略决策**。

**物流系统**——三阶段递进是品类中公认最完善的设计：

| 阶段 | 物流方式 | 核心里程碑 |
|------|---------|-----------|
| 1. 传送带 | 黄(15/s) → 红(30/s) → 蓝(45/s)，地下带，分流器，叠加式传送带(Space Age) | 蓝瓶解锁后工厂规模质变 |
| 2. 铁路 | 区块信号+链式信号，高架铁轨(Space Age)，火车时刻表中段(Space Age) | 信号系统是著名的新手杀手 |
| 3. 物流机器人 | 施工机器人（按蓝图自动建造），物流机器人（箱网络自动搬运） | 从"手放一切"到"设计蓝图→机器人建造"的质变 |

**电路网络**——可编程逻辑层。红/绿电线连接实体，常量/判定/算术/选择运算器构建条件逻辑。与 Mindustry 的汇编式 VM 相比，Factorio 更偏向**数据流**思维。

**污染与虫族进化**——品类中最成熟的 PvE 压力系统。进化因子（0→1）由时间、污染总量、虫巢摧毁数三维驱动，**只增不减**。污染对进化的贡献基于**总产量而非扩散量**——效率插件是唯一减缓进化速率的手段。攻击波以污染吸收量触发（每吸收 200 污染召唤一只小虫子）。

**品质系统（Space Age）**——五级品质（Normal → Uncommon → Rare → Epic → Legendary）。4 个传奇品质模块 3 下，从普通原料直接产出传奇物品的概率仅 **0.0248%**。升级循环（Upcycling）结合回收机（25% 回收率）和高级生产建筑（50% 基础生产力），可将每传奇工艺次数从 1,546 降至 14-36 次。

**腐败系统（Gleba）**——强制"库存导向"向"流动导向"转变。所有生物产品有固有腐败计时器（营养液 5 分钟，五足虫卵 15 分钟后孵化出五足虫）。缓冲囤积是陷阱，所有生产必须基于吞吐量设计。这是品类中独一无二的机制。

#### 2.1.3 技术树设计

**七种科技瓶体系**构建了从简单到复杂的递进式解锁：

| 科技瓶 | 关键挑战 | 节点意义 |
|--------|---------|---------|
| 红（自动化） | 铁+铜齿轮——最简配方 | 教程 |
| 绿（物流） | 传送带+插入器 | 推动自动化产线 |
| 黑（军事） | 弹药类产品 | 可选，仅影响战斗 |
| 蓝（化工） | 石油加工+发动机+硫磺+高级电路 | **主要难度跃升**，新手常见弃坑点 |
| 紫（生产） | 大量电路+钢 | 迫使大规模扩张 |
| 黄（通用） | 最复杂配方，含固体和液体原料 | 火箭发射前的终极考验 |
| 白（太空） | 仅从火箭发射获得 | 无尽科技入口 |

**设计哲学**：每个新科技瓶类型**强制**玩家接触一个新游戏系统，创造出"工厂必须增长"的循环。**Space Age 将火箭发射从终点变为中点**——之后四个新星球各有专属科技瓶（冶金、电磁、农业、低温），通关时间从 20-30 小时扩展至 100+ 小时。

#### 2.1.4 独特优势

1. **技术成就**：确定性的多星球工厂模拟，运行数万个实体，跨多表面、星际货船、移动太空平台——全部 30-60 FPS。是品类中无可争议的性能基准。
2. **Mod 生态**：5,000+ Mod，从 Krastorio 2（约 30 小时）到 Space Exploration（约 300 小时）到 Pyanodon's（"Factorio 的黑魂"），层次分明，适合不同耐心度的玩家。
3. **"永不打折"政策**：$35 基础版 + $35 Space Age，从未打折。塑造了独特的社区文化——没有"等打折"文化，减少了负面评价。
4. **内置 Mod 管理器**：刻意不使用 Steam 创意工坊，自建门户提供版本控制、存档级 Mod 配置。

#### 2.1.5 不足与争议

- **铁路信号系统**是经典的新手杀手
- **蓝瓶阶段（石油加工）**是主要玩家弃坑点
- **Gleba 星球**（Space Age）高度两极分化——腐败机制让首次到达的玩家大面积崩溃
- **品质系统**的电路网络支持不足（无通配符、无 >= 品质比较器）
- 后期大规模火车和机器人管理存在 QoL 缺口

#### 2.1.6 适合的玩家

- 软件工程师/工程师/数学家的最爱——与专业思维模式高度共鸣
- 追求 100+ 到数千小时深度投入的玩家
- 喜欢工程设计、优化和系统思维的玩家
- 对"解决一个问题后产生十个新问题"的循环不感到沮丧的玩家

### 2.2 像素工厂（Mindustry）

#### 2.2.1 核心玩法循环

```
采集资源 → 搭建传送带物流链 → 生产弹药供给炮塔 → 防守波次敌人进攻
    ↑                                                      ↓
    └────────── 生产作战单位反攻敌方基地 ← 占领星区解锁新技术 ←──┘
```

Mindustry 是 Factorio + 塔防 + RTS 三种类型的杂交体。与 Factorio 的根本差异：**建造和战斗是同时进行的**，不是在战斗间隙建造，而是在敌人波次到来期间持续优化工厂布局。

#### 2.2.2 系统深度

**物流系统 vs Factorio**：

| 维度 | Mindustry | Factorio |
|------|-----------|----------|
| 空间约束 | 紧凑——地图有边界，布局效率至上 | 几乎无限 |
| 资源枯竭 | 永不枯竭 | 有限（除水/油外） |
| 物流天花板 | 中等——无火车、无物流机器人、无电路网络 | 极高 |
| 3D 传送 | 桥接带、塑钢带（远距离直送） | 地下带 |

**资源链**——Serpulo（16 种材料，138 方块，18 炮塔，35 单位）和 Erekir（10 种材料，102 方块，10 炮塔，15 单位）双星球，Erekir 更聚焦线性但管道系统有独特逻辑。

**逻辑处理器**——Mindustry 的秘密武器：内置于游戏中的**汇编式虚拟机**（20+ 指令类型，每处理器最多 1000 条指令），图灵完备性强于 Factorio 电路网络。社区甚至有 Python→Mindustry 汇编的编译器（Pyndustric）。

**星球征服元游戏**——双层级结构（Planet → Sector），后台确定性 DPS 数学模拟无人驻守扇区的防御。跨区资源运输（发射平台 + 全局池）和入侵机制（敌方邻居反攻）增加了战略层。

#### 2.2.3 技术树

- **有向无环图（DAG）**结构，双星球独立树
- 解锁条件：父节点已解锁 + 资源消耗 + 游戏目标（占领扇区、生产特定物品）
- 6 种可见性门控条件

#### 2.2.4 独特优势

1. **类型融合独一无二**——在工厂建造、塔防、RTS 三角色中找到了独特定位
2. **完全开源（GPLv3）**，跨平台（PC/Android/iOS），存档/Mod 全平台兼容
3. **极低配置要求**——"土豆机"优化使其在低配设备和手机上流畅运行
4. **内置地图编辑器和蓝图系统**，130+ 官方地图
5. **性价比极高**——免费（Android/iOS）或极低价（Steam ~$6），数百小时内容量

#### 2.2.5 不足与争议

- **V8 更新争议（2024-2025 最大争议）**：削弱跨区资源支援，移除动态多线战争前线，多位老玩家警告"玩 V7，别碰 V8"
- **重复性负担**：每个星区从头重建相同基础设施，"离开基地、每次落地重建相同布局无法满足创造欲"
- **后期公式化**：所有科技解锁后每个星区打法趋同
- **单位管理缺陷**：无法删除单位，只能沉矿渣或利用漏洞
- **学习曲线陡峭**：引导不足，Erekir 管道图标"颜色和图案几乎一样"但功能不同

#### 2.2.6 适合的玩家

- 喜欢塔防+工厂建造组合的玩家
- 想要快速行动（每局 30-90 分钟给 vs Factorio 数百小时）
- 对 RTS 战斗感兴趣的工厂游戏玩家
- 预算有限或想在手机上玩的玩家

### 2.3 戴森球计划（Dyson Sphere Program）

#### 2.3.1 核心玩法循环

```
母星资源采集 → 矩阵方块研究 → 解锁星际航行 → 跨行星资源获取
      ↑                                                  ↓
      └──── 戴森球建造（反物质→白糖→无限科技）←──────┘
```

DSP 的核心创新是将工厂自动化从平面地图扩展到**球面行星 + 星际空间**的双层尺度。物流系统以行星物流站（PLS）和星际物流站（ILS）为节点，构造多层级供应网络（采矿星球 → 冶炼星球 → 组装星球）。ILS 的两套独立设置（Local/Remote Supply/Demand 可任意组合）被社区称为"明显的天才设计"。

#### 2.3.2 系统深度

**生产链**——以小型运载火箭（1 枚/分钟）为例，需要 9 种原材料（铁 699、铜 280、硅 414、煤 281、钛 163、石 163、氢 136、原油 256、水 74），涉及 15+ 个中间产品，跨越多个行星。

**物流**——ILS 的核心参数：5 个物品槽（vs PLS 的 4 个），无人机容量 100（vs PLS 50），物流船容量 10（需曲速飞行需 Lv.4 引擎）。2024 年更新引入物流优先级系统（点对点配对 > 星际路线 > 编组 > 普通配对 > 忽略配对）。

**能量系统**——分阶段推进。从风力（300 kW/台）→ 太阳能（赤道环绕是经典策略）→ 微型核聚变（15 MW）→ 戴森云+射线接收站（6-60 MW）→ 人造恒星（72 MW/颗，燃烧反物质燃料棒）。

**关键差异**：与 Factorio 相比，液体在 DSP 中是固态方块（可走传送带），**彻底消除了管道系统的复杂性**——部分是便利性优势，部分是深度削减。稀矿系统（有机晶体矿脉、硫酸海等）允许绕过复杂生产链直接开采成品——这是 Factorio 没有的"探索奖励"。

#### 2.3.3 技术树

**六种矩阵方块体系**是 DSP 最核心的设计：

| 矩阵 | 阶段 | 关键约束 | 独特意义 |
|------|------|---------|---------|
| 蓝（电磁） | 早期 | 磁线圈+电路板 | 入门自动化 |
| 红（能量） | 早期 | 高能石墨+氢 | 石油化工引入 |
| 黄（结构） | 中期 | 金刚石+钛晶 | **必须离开母星获取钛**——第一个强制扩展节点 |
| 紫（信息） | 中后期 | 处理器+粒子宽带 | 工厂需大规模扩张 |
| 绿（引力） | 后期 | 引力透镜+量子芯片 | 需稳定大型电力 |
| 白（宇宙） | 终局 | 前五种各 1 + 反物质 | 无限重复升级 |

矩阵实验室双模式（生产/研究）+ 垂直堆叠（最高 15 层）是 DSP 的独特机制。

#### 2.3.4 独特优势

1. **球面建造**——品类中唯一在球面网格上运行自动化游戏的产品，带来独特的设计挑战（极地扭曲、有限表面积、行星自转影响）
2. **视觉奇观**——实时观看戴森球从无到有在建，"无与伦比的规模感"
3. **ILS 系统直观强大**——跨行星物流设罝极其简单，"明显的天才设计"
4. **中国独立团队**——5 人初始团队（重庆柚子猫），全球销量超 300 万套，97%+ Steam 好评
5. **所有大型更新免费**（黑雾、多线程重构、未来的载具与空间站）

#### 2.3.5 不足与争议

1. **终局空虚**——戴森球完成后缺乏有意义的目标。"能量危机从未真正存在。"完整的戴森球提供的冗余能量远超游戏任何消耗需求
2. **EA 时长**——2021 年 1 月上线至今已超 5 年半，仍无 1.0 正式发布日
3. **缺失基础 QoL**——基地照明、导航/标签系统、云存档（存档文件可达 1GB+）
4. **无原生联机**——Nebula mod 存在但限制多
5. **蓝图受限**——与 Factorio 的"强制建造"不同，DSP 蓝图有冲突即全盘失效
6. **黑雾战斗不完整**——太空战斗"仍然很差"，地面战斗缺乏深度
7. **开发节奏缓慢**——"创建系统"（载具+空间站）迟迟未上线。核心研发不足 10 人

#### 2.3.6 适合的玩家

- 追求"禅意规模感"和"星际奇观"的玩家
- 喜欢 DSL 直观物流而非深度细节优化的玩家
- 对戴森球/太空殖民主题有特别兴趣的科幻爱好者
- 愿意为 5 人团队的野心之作给予耐心的玩家

## 三、A 级游戏分析

### 3.1 3D 探索-自动化组：Satisfactory vs Astroneer

两者都是 3D 第一/第三人称、手工打造的世界、探索驱动。但自动化深度天差地别。

#### Satisfactory（幸福工厂）

**核心定位**：唯一真正做到"第一人称 + 全自由 3D 垂直建造"的工厂游戏。

**规模数据**：
- 地图 47.1 km²，手工人造，21 个生物群落，垂直高差 488m
- 550 万份销量（截至 2024 年 1 月），1.0 正式版 2024 年 9 月发布
- Metacritic 91/100，Golden Joystick 2024 PC Game of the Year
- Tier 0-9 九级科技，Space Elevator 五阶段门控

**物流体系**——五级物流递进：
1. 传送带 Mk.1-6（60→120→270→480→780→1200 items/min）
2. 管道 Mk.1-2（300→600 m³/min）
3. 车辆（拖拉机→卡车）
4. 电力火车（Block/Path Signals，电网供电 25-110 MW）
5. 无人机 + 传送门（Tier 9 量子时代）

**资源设计**——矿点永不枯竭（与 Factorio 根本差异），节点纯度决定矿机输出（Impure/Normal/Pure → Mk.3 矿机最高 480/min）。4 个铀节点是核能上限的硬约束。

**独特机制**：
- **Mercer Spheres（298 个）**：解锁云端仓库 Dimensional Depot，彻底改变背包管理
- **Somersloops（106 个）**：生产增幅（"slooping"），放入生产建筑可翻倍输出，功耗增至 4 倍
- **Hard Drives（118 个）**：扫描获得替代配方。1.0 引入 Hard Drive Library 暂存不选择

**替代配方系统**——是最被低估的深度来源。如 Cast Screws（5 Iron Ingot→20 Screws，省去 Iron Rod 中间环节）、Solid Steel Ingot（Iron+Coal 2:2→3）、Diluted Fuel（HOR+水→更多燃油），每一个替代配方都是一次"工厂重设计"的机会。

**主要不足**：
- 蓝图系统远逊于 Factorio（物理尺寸上限、需物品在背包、不可包含矿机）
- 无电路/逻辑网络系统
- 大工厂性能下降严重（RTX 4070 也可能 10-15 FPS）
- Mk.5 传送带存在已知吞吐量 bug（1200 理论值在长距离无法稳定达到）
- 手工地图限制重玩性

**vs Factorio 的精确定位**：
> Factorio = 国际象棋——纯系统优化、2D、无限扩展、深度蓝图、电路网络
> Satisfactory = 精美棋盘上的跳棋——3D 探索 + 美学 + 放松建造

#### Astroneer（异星探险家）

**核心定位**：**探索/创造沙盒，带自动化装饰。** 完全不属于硬核自动化游戏。

自动化水平评分（与 Factorio 对比）：

| 维度 | 评分 |
|------|:--:|
| 自动化深度 | 2/10 |
| 制造复杂度 | 3/10（2-4 阶链，无替代配方、无品质层级） |
| 物流 | 4/10（Auto Arms 是唯一物品搬运机制，铁路利用率低） |
| 沙盒/创意 | 8/10（体素地形变形独树一帜） |
| 视觉/氛围 | 9/10 |

**核心系统**：
- 体素地形变形——全 3D 体积地形可任意挖掘/升起/平整。被称为"太空橡皮泥" vs Minecraft 的"乐高积木"
- 资源行星门控——Tungsten (Desolo) → Iron/Titanium/Argon (Glacio) → Helium (Atrox)，不是技术树解锁而是行星访问解锁
- 土壤离心机——用通用土壤生产任何基础资源，"深度杀手"——任何一块土可以变成任何资源

**社区定论**：Astroneer 是与 Subnautica 和 No Man's Sky 同类的探索/制造游戏，按 Steam 标签搜"Automation"会被视为误导。典型的玩家评语："这个游戏的自动化形同虚设。你永远不需要如此大量的物品以至于需要自动化。"

**参考价值**：对于自动化游戏分析，Astroneer 主要作为**对照案例**——展示一款游戏可以在自动化极浅的情况下仍被 Steam 算法标记为"自动化"，以及玩家为什么拒绝这种分类。

### 3.2 生存-自动化组：Oxygen Not Included vs Captain of Industry

两者都是将自动化作为核心工具但以**生存压力**为第一驱动力的游戏。共同特点是"从蛮荒到工业化"的文明建设叙事。

#### Oxygen Not Included（缺氧）

**核心定位**：**热力学模拟殖民地生存游戏。** 品类中物理模拟最深的游戏之一。

**核心区别化特征**：与 RimWorld（社会关系驱动）和 Factorio（工厂增长驱动）不同，ONI 的核心驱动是**物质科学和热力学**。

**物理模拟**：
- 元胞自动机模型——每格仅与 4 个直接邻居交互，对角线无互动
- 气体/液体按**固定密度排名**分层（氢气浮最上 → 氧气 → 氯气 → CO₂沉底）
- **无理想气体定律**——温度不影响密度或压力。压力本质上是每格质量（kg/tile）
- 热传导基于比热容（SHC）和导热系数（TC）。温差 < 1°C 无热传递
- 关键工程概念：AT/ST（液冷器+蒸汽涡轮机）闭环——蒸汽涡轮机将 125°C+ 蒸汽消耗并输出固定 95°C 水，**删除约 90% 的热量**

**自动化系统**：
- 信号网络（自动化线/Ribbon）支持温度、气压、液体/气体元素等传感器
- 逻辑门：与、或、非、异或、缓冲器、滤波器、SR 锁存器
- 传送带系统（Conveyor Rail）+ 自动清扫器实现资源自动分拣
- 应用：全自动厨房、全自动煤炭供应、工业分拣中心

**复制人系统**——7 个核心需求维度（呼吸、卡路里、膀胱、体力、体温、士气、压力），兴趣+特质系统，仿生复制人（Bionic DLC, 2024）引入完全不同的需求（电池电量代替食物，齿轮油代替厕所，碎片整理代替睡眠）。

**"解决方案制造新问题"设计哲学**——这是 ONI 为自动化品类贡献的最重要设计原则：

```
电解水制氧 → 氢气（爆炸风险）→ 需要分离+存储
          → 氧气 70°C 出口 → 需要冷却
                          → 液冷器产更多热 → 需要蒸汽涡轮机
                                            → 需要钢 → 需要精炼铁+煤炭+石灰
                                                      → 石灰来自蛋壳 → 需要畜牧业
```

**技术树**——12 大类别（食品、电力、固体材料、液体、气体等），4 级研究站（Novice → Advanced → Interstellar → Materials Science），火箭系统 + Spaced Out! DLC 多星球管理。

**关键数据**：
- Steam 好评如潮（约 96-97%），Metacritic 用户 8.2/10
- 常见游戏时长 100-9,000+ 小时（极端留存）
- 最佳学习路径：只玩基础游戏（非 DLC），先靠失败学习，逐系统攻克

**主要不足**：
- 学习曲线是"悬崖"而非曲线
- 教程缺失，信息分散——需要大量外部 wiki 和视频辅助
- 病菌/疾病系统被社区认为未充分发展
- AI 路径规划——复制人做出不合逻辑的选择
- 后期 DLC 被批评为"buggy"和"overpriced"

#### Captain of Industry（工业巨头）

**核心定位**：**地形改造 + 车辆物流 + 殖民地生存的工业建造游戏。** 是品类中"副产品管理"最硬核的代表。

**规模数据**：
- 150-200+ 种独特产品，岛屿最大 65,000 格（约 260 km²）
- Steam "Very Positive"（~90%），10,500+ 评价，56 万+ 份销量
- 抢先体验（2022 年 5 月起），预计还要 2-4 年才到 1.0
- 约 8-12 个月一次大版本更新（最近：Update 4, 2026 年 3 月）

**核心差异化特征**：

1. **完全动态地形**——品类中独一无二。地形不是背景而是物理实体：挖山填海、矿坑随开采下沉、256 种材质独立物理参数。采矿会**物理性降低地形**——露天矿坑随着开采逐渐凹陷。这改变了"在哪里建造"的计算方式。

2. **以车辆为中心的物流范式**——不同于 Factorio 的传送带优先和 Satisfactory 的 3D 传送带，CoI 的核心运输媒介是**有油耗的卡车车队**。卡车自动在仓储、矿区、工厂之间运输。传送带/管道是补充而非主力。Update 3/4 加入火车和两栖车辆。

3. **死亡螺旋（Death Spiral）**——品类中最著名的生存挑战：一旦某个关键资源（柴油、维护、食物）断供，在几分钟内引发连锁崩溃——机器停摆→维护无法生产→更多机器停摆→食物断供→人口流失→劳动力不足→彻底崩溃。

4. **工人福祉即生产资源**——Unity（凝聚力）是核心资源。定居点需要多样化的食物（碳水化合物、蛋白质、维生素、甜点四类）、饮用水、电力、污水处理、医疗用品来维持。人口会生病、会死亡。

5. **副产品是核心博弈**——几乎所有机器都产生副产品（废气、酸性水、硫磺、矿渣、核废料）。水污染惩罚是**全域的**——即使定居点有清洁水供应，只要岛上任何地方排放了污水，全岛人口都受健康惩罚。

6. **维护经济**——三档不可互替的维护等级（I/II/III），维护低于 75% 时设备有概率故障。闲置建筑消耗 33% 维护，暂停建筑消耗 0%。"维护瘫痪"是一种核心失败模式。

**生产链示例**——石油化工：原油→多级精炼（石脑油、柴油、重油、轻油）→化工中间体（氢气、氨、硫酸、肥料）→塑料、橡胶、合成材料。电子工业：硅→多晶硅→微芯片→PCB→服务器→消费电子 I/II/III。核工业：铀矿→黄饼→浓缩铀→铀棒→核反应堆→乏燃料后处理→钚提取→MOX 燃料→快中子增殖堆（可实现自持燃料循环）。

**主要争议——EA 中发布付费 DLC**：这是 2025-2026 年最主要的负面评价来源。开发者在游戏尚未完成时发布了含列车玩法的付费 DLC。大量数百小时玩家因此改为差评。开发者对批评的情绪化反应也有争议。

**vs Factorio 的精确定位**：
- Factorio = "走广度路线"（无限地图、无限 Mod 扩展、近乎无限规模）
- CoI = "走深度路线"（更深的单产品链、更真实的工业过程、更残酷的失败后果）
- CoI 的生产链单线更深（150+ 产品 vs Factorio 基础版的 ~100 种中间品），但多样性更窄（无替代配方、无品质层级、无模块系统）
- CoI 的失败后果更严重（死亡螺旋不可逆 vs Factorio 可重建），但灵活性更低（无蓝图、无 construction bots）

### 3.3 纯解谜-自动化组：Shapez vs Infinifactory

两者都将自动化提炼为**纯粹的几何/空间解谜**，剥离了资源管理、生存、战斗等要素。适合"单纯想要优化挑战"的玩家。

#### Shapez（异形工厂）

**核心定位**：**所有"生存"要素被彻底剥离的纯粹自动化体验。**

**四零设计**：零战斗、零资源成本（建筑和传送带完全免费）、零时间压力、零故事/世界观。Rock Paper Shotgun 称之为"工厂游戏爱好者的纯粹猫薄荷"。这种"去生存化"设计的心流状态极其容易进入（Zeigarnik 效应），但也可能导致部分玩家缺乏目标感和动力。

**四种核心操作驱动全部复杂度**：
1. 切割（沿四分线切割）
2. 旋转（90° 旋转片段）
3. 堆叠（双层→ Shapez 2 扩展至四层）
4. 上色（RGB 三原色，可混合为二次色及白色）

**组合爆炸**：四种操作的排列组合产生数百种独特配方。后期玩家需要从 `CbCuCbCu:Sr------:--CrSrCr:CwCwCwCw` 这样的加密形状编码中反向推演设计方案。

**关键机制**：
- 逻辑电路系统——解锁后可构建**万能制造机（MAM）**——无需人工干预即可自动识别任意形状并生产的全自动工厂
- 蓝图系统——被广泛赞誉为"工厂游戏类型中最好的蓝图系统"

**Shapez 2 的关键改进**（2026 年 4 月 1.0 正式版）：
- 图像从 2D 俯视升级为 3D，支持多层建造和 360° 旋转视角
- 运输系统加入空间列车、空间管道、流体
- 形状层数从双层扩展至最高四层
- **制造模式（Manufacture Mode）**——1.0 的核心创新，回应 EA 最大的反馈"工厂缺乏持久性"。贸易站系统替代漩涡，构建永久性自增长工厂网络

**商业数据**：EA 销量 650,000-700,000 份，Steam 97% 好评如潮，Metacritic 80/100。获德国联邦政府 €537,833 游戏开发资助。

**适合的玩家**：自动化游戏新手（引导出色、试错成本为零）、追求心流体验的人、数电/工程/编程爱好者。

#### Infinifactory（无限工厂）

**核心定位**：**关卡制 3D 体素自动化解谜**，Zachtronics 出品。

**与开放世界自动化游戏的核心区别**：

| 维度 | Infinifactory | Factorio/Satisfactory |
|------|-------------|----------------------|
| 类型 | 有最优解的空间解谜 | 无最优解的工程沙盒 |
| 资源管理 | 无（无限输入） | 有限矿脉/节点 |
| 敌对压力 | 无 | 有（虫子/野生动物） |
| 复杂度来源 | 空间约束 + 解最优性 | 物流扩展 + 生产比例 |
| 可重玩性 | 关卡重解 + 工坊 | 近乎无限 |

**三种优化指标（互斥式设计）**——每个关卡通关后显示直方图，比较在三个独立维度上的表现：
1. **周期数**——工厂运行速度
2. **方块数**——使用的功能方块总量
3. **占地面积**——工厂的水平投影面积

由于三个指标通常互斥，每关提供三个存档位鼓励分别优化。**直方图而非排行榜**展示玩家社群分布——不暴露精确排名，在保持竞争激励的同时避免挫败感，被称为"天才级设计决策"。

**战役结构**：两个战役（Overlord 主线 + Resistance 反抗军），约 50+ 个谜题关卡，另有沙盒和 Steam 创意工坊。

**主要不足**：
- 不支持复制粘贴大范围方块选择——这是最多人诟病的问题
- Resistance 战役后期关卡变为"体力活"——用旧工具完成极端复杂空间管理
- 3D 眩晕——多名玩家报告第一人称视角引发的晕动症
- PC 版无手柄支持（十年未更新）
- 方块种类有限——与 Opus Magnum/EXAPUNKS 相比工具集简单

**在 Zachtronics 产品线中的位置**：中游作品——比 SpaceChem 更易上手，比 Opus Magnum 更粗糙，比 Shenzhen I/O 更直观。对于 Zachtronics 新手，Opus Magnum 通常被推荐为更佳入门选择。

### 3.4 战斗-自动化组：Cosmoteer vs The Riftbreaker

两者都将战斗作为核心输出，但自动化/建造层服务于完全不同的战斗范式。

#### Cosmoteer（星际飞船设计师兼舰长）

**核心定位**：**舰船设计 + 船员物流模拟 + 实时战术战斗。** 自动化表现为"通过布局设计使模拟船员自动高效运转"。

**核心动力学**：
- 舰船建造在 2D 网格上自由放置模块（武器、护盾、引擎、反应堆、船员舱、走廊）
- 每个船员独立模拟——物理性地搬运弹药/电池/资源在模块间移动
- 炮台开火频率、护盾充能速度直接取决于船员从弹药工厂/反应堆到武器/护盾的步行距离
- 物理模拟弹道轨迹（无骰子命中判定），模块逐块计算损坏，反应堆/弹药工厂会爆炸产生链式反应

**进程系统**——Fame 系统（无传统科技树）：
- Fame 是唯一进程标尺兼资源兼胜利条件
- 船员数量直接由 Fame 等级限制（0 Fame → 24 船员，10,000 Fame → 1,500 船员）
- 蓝图从空间站购买，理论上早期可买到几乎所有设备——但**能否实际使用取决于船员上限**
- Fame 获取：完成任务 + 摧毁比你 fame 更高的敌舰。每个区域有 Fame 上限——到达后**必须前往更高难度星区**

**设计争议**：Fame/船员上限被玩家视为"人为制造的限制"和"过于 grind"。生涯模式被广泛认为是最薄弱的环节——任务类型单一，无实质剧情，无外交/派系系统。

**对自动化品类分析的价值**：
- 布局优化的多层反馈（一个模块的改变引发级联的物流、动力、结构重优化）——与大型工厂重构的体验同构
- "瓶颈可视化"——船员拥堵、供给不足直接表现为武器停火/护盾失效，实时、可视、可诊断
- 物理后果叠加策略选择——反应堆放哪里是生存与火力的权衡

#### The Riftbreaker（银河破裂者）

**核心定位**：**塔防 + 双摇杆 ARPG + 基地建造 + 轻度自动化。** 不是自动化游戏。

**多重融合的分解**：

| 层 | 类型 | 实现 |
|----|------|------|
| 战斗 | Twin-stick ARPG | 机甲直接操控，2 武器槽，元素伤害类型 |
| 防御 | 塔防 | 波次敌军进攻，多种炮塔，需能量+AI 核心 |
| 经济 | 基地建造 | 资源采集，简化产链，电网管理，技术树 |
| 探索 | 开放世界 | 多生态区，程序生成地图，扫描动植物 |

**自动化水平**：
- **无物流层**——所有资源瞬间传送到全局仓库，无传送带/火车/无人机/搬运器
- **制造链不超过 3 步**
- **研究是时间门控而非资源门控**——不能通过建造更多实验室加速
- 电力系统有更多深度——电网+AI 处理能力双约束

**社区定论**：_"这不是自动化游戏。Factorio 是关于生产和运输机制的。Riftbreaker 是关于战斗策略和战术的。"_

**独特亮点**——外星研究熟悉度系统（扫描/击杀生物解锁科技）是品类中缺乏的创新进步机制。机甲主角（Mr. Riggs）作为建造与战斗之间的桥梁。裂缝传送门快速旅行（免费、即时、无冷却）。

## 四、B 级游戏简要概述

B 级游戏体量和系统深度明显低于 S/A 级，但各有独特的切入角度。整体而言，这四款游戏**不以自动化深度见长**，更多作为特定子类型的代表或对照案例。

### 4.1 火车物流解谜：Railgrade（铁路调度模拟器）

**核心定位**：披着火车模拟外衣的**物流解谜游戏**，不是自动化沙盒。

- 约 50 个手工设计任务关卡，S/A/B/C 评级系统
- 34 种资源，46 种工业类型。一切运输必须由火车完成
- 无信号系统，火车可互相穿模（缓慢通过）
- 社区共识："更像一个传送带模拟器——调整输入工厂和城市的速率才是关键"
- 评级系统造成玩家分裂——部分人喜欢结构化目标，另一部分人反感时间压力
- Metacritic 88%，Steam"特别好评"
- **参考价值**：火车作为唯一物流载体的极端设计实验。关卡制约束适合短周期玩家（20-40 小时），但缺乏沙盒的持久吸引力。

### 4.2 星球改造物流：Plan B: Terraform（B 计划：星球改造）

**核心定位**：**星球改造物流游戏**，自动化极简化。

- 最终产品是星球本身——通过工业供应链升温大气、融化冰层、种植森林、提高氧气
- 物流极度简化——车辆穿模无障碍，无传送带拼图，无路由优化
- 星球改造是品类中独一无二的系统（1M+ 六边形实时全球模拟），但**被动性太强**
- 无科技树（资源精炼链即进阶），23 个故事关卡
- Steam Very Positive（91%, ~1,400 评价），$15.99
- **参考价值**：自动化游戏新手的理想入门作，休闲禅意体验。证明"自动化作为星球改造工具"的概念可行，但深度不足以支撑长期留存。

### 4.3 移动端极简自动化：Assembly Line（流水线：汽车工厂模拟）

**核心定位**：移动端 **"Factorio 去敌去资源版"** 网格解谜。无中文。

- AL1 6×6→16×16 网格；AL2 10×10→100×100（10,000 机器槽位）
- AL2：50+ 资源，21+ 机器类型，分支死胡同→线性化科技树
- AL1 已废弃（2018 年后无更新），AL2 稳定性差（频繁崩溃）
- 纯空间优化谜题，"自动化极乐"但最终受无复制粘贴的折磨
- 约 10-20 小时的乐趣窗口
- Google Play 4.4/5（78K 评价），1M+ 下载
- **参考价值**：品类中罕见的原生移动端自动化游戏。证明触屏界面可承载工厂建造玩法，但缺乏蓝图/复制粘贴等核心 QoL 导致乐趣窗口极短。

### 4.4 生存建造 + 迟到的自动化：The Planet Crafter（星球工匠）

**核心定位**：**生存建造为主，自动化是极后期的减负手段。**

- 生存建造+增量游戏基因。自动化（无人机站+自动制造机+矿石提取器）在改造指数达到 **62.5 GTi** 时才解锁——此时玩家已手动完成了大部分内容
- 四维改造体系（氧气/热量/气压/生物量）+ 15 个视觉阶段
- Steam 96% 好评如潮，37,000+ 评价，100 万+ 销量
- **关键设计教训**：自动化作为后期减负手段而非核心玩法循环。自动化在游戏中出现太晚/太浅——自动化系统需要从早期就作为核心乐趣引入，否则沦为"锦上添花"而非"核心驱动力"。

## 五、跨游戏系统设计对比

### 5.1 技术树设计模式对比

自动化游戏的科技推进系统可分为四大模式：

#### 模式一：科技包/研究瓶模式

**代表**：Factorio, DSP, Mindustry

**核心机制**：玩家建造工厂生产专门的"研究消耗品"（科技瓶/矩阵方块），将其持续送入研究建筑。研究不是"点一下然后等"，而是对工厂产出的持续资源消耗。

**关键特征**：
- 科技瓶的复杂度递增**强制**玩家接触新系统（如 Factorio 的蓝瓶强制学习石油加工）
- 研究速度 = 工厂生产研究消耗品的能力——"研究瓶颈"就是"工厂瓶颈"
- 创造自指循环："更好的工厂 → 更快的研究 → 更好的科技 → 更好的工厂"

**优劣分析**：
- **优势**：深度集成到核心循环中，规模化研究需要规模化工厂，自驱动力强
- **劣势**：学习曲线陡峭（蓝瓶阶段是著名的玩家弃坑点），需要玩家自驱规划

#### 模式二：里程碑/任务解锁模式

**代表**：Satisfactory（HUB Milestones + Space Elevator Phases + MAM）, Shapez（关卡里程碑）

**核心机制**：递交指定物品完成任务来解锁下一级。制造品是**分数/通行证**而非持续消耗品。研究没有"速率"概念——只有"达到产出合格线"这一个门槛。

**关键特征**：
- 阶段门控（如 Satisfactory 的 Space Elevator 五个 Phase）确保玩家达到特定产能后才解锁新内容
- Shapez 的解锁节奏最小化——每个里程碑只引入一种新操作
- MAM 辅助研究提供替代配方的横向扩展

**优劣分析**：
- **优势**：目标明确，适合引导型玩家，难度曲线可控
- **劣势**：缺乏"研究速率"的优化维度，研究是"点一下"而非持续工程挑战

#### 模式三：研究点数积累模式

**代表**：ONI（研究站消耗土料/水/数据银行/Radbolt）, Astroneer（Bytes 消耗）, Captain of Industry（实验设备+研究点数）

**核心机制**：有一个研究速率（实验室对特定资源的消耗速率），研究门控为"点数达标后解锁"。不是"递交产品"模式，也不是"消耗特定科技包"模式。

**关键特征**：
- ONI 需要通过超级计算机消耗清洁水→这推动了水循环系统的建造
- CoI 需要生产实验设备供给实验室，且在特定难度阈值以上需要更高等级的实验室能——这迫使工厂同时生产科研消耗品和其他产品
- Astroneer 的 Bytes 获取可以自动化（Auto Arm + Research Chamber 无限循环）

**优劣分析**：
- **优势**：比里程碑模式更深度但不需专门的科技包生产线，在生存游戏中自然融入
- **劣势**：缺乏科技包模式的"工厂规模→研究速度"正反馈循环

#### 模式四：关卡渐进解锁模式

**代表**：Infinifactory, Railgrade

**核心机制**：完成前一关解锁后一关。新方块/机制在特定关卡被引入，先教学再整合再精通。

**关键特征**：
- 设计师完全掌控玩家何时接触何种机制
- 每关是独立空间，无持久世界
- Zachtronics 的标志性教学法："引入→组合→精通"

**优劣分析**：
- **优势**：学习曲线最可控，设计师意图最清晰，适合解谜驱动的体验
- **劣势**：缺乏开放世界的自驱探索感，重玩价值完全依赖关卡重解和工坊

#### 四种模式的本质差异

```
             规模化自由度
                  ↑
    科技包模式    │
    (Factorio)    │    里程碑模式
                  │    (Satisfactory)
                  │
  ────────────────┼────────────────→ 结构引导性
                  │
    点数积累模式  │
    (ONI, CoI)    │    关卡解锁模式
                  │    (Infinifactory)
                  ↓
```

- **科技包模式**：规模化自由度最高，结构引导性最弱——玩家必须自驱
- **关卡解锁模式**：结构引导性最强，规模化自由度最弱——设计师说了算
- **里程碑模式**：两个维度折中——有结构但留空间给玩家
- **点数积累模式**：研究是副系统而非主循环——在生存游戏中合理，在纯自动化游戏中显得薄弱

### 5.2 物流系统设计对比

#### 5.2.1 传送带系统

| 游戏 | 传送带设计 | 等级递进 | 独特机制 |
|------|-----------|---------|---------|
| **Factorio** | 2D 网格，基础/快速/极速带，地下带，分流器/合流器 | 黄(15)→红(30)→蓝(45) items/s | 带平衡器（belt balancer）是社区核心优化技术；Space Age 叠加式传送带（Stack Inserter）一格堆叠多物品 |
| **Mindustry** | 2D 网格，基础/钛/装甲/塑钢/相位带，桥接带 | 多种带各司其职 | 路由器、分类器、溢出门、下溢门——分流逻辑比 Factorio 更丰富；塑钢带远距离直送 |
| **Satisfactory** | 3D 世界，传送带 Mk.1-6 | 60→120→270→480→780→1200 items/min | 传送带提升机（Conveyor Lifts）实现层间垂直运输——品类唯一的三维传送带系统 |
| **DSP** | 3D 球面，多级传送带 | 多级速度 | 液体为固态方块走传送带——消除了管道系统 |
| **Shapez** | 2D/3D，统一速度传送带 | 无等级，吞吐量由分流决定 | 空间列车+空间管道（Shapez 2）替代长距离传送带 |
| **Captain of Industry** | 3D 俯视，单面单向，垂直堆叠 4 层 | 多种带 | 无地下传送带；车辆是主力运输而非传送带 |
| **ONI** | 2D 横切面，传送带轨道（Conveyor Rail） | 单一系统 | 轨道元素传感器+自动卸货器——可与信号逻辑联动 |
| **Infinifactory** | 3D 体素网格传送带 | 单一方向+倒置带 | 单传送带驱动任意尺寸物体；优先级规则：东西向 > 南北向 |
| **Assembly Line** | 2D 网格基础传送带 | 单速 | 空间极为受限——传送带布局就是全部游戏性 |
| **Plan B** | 无传送带系统 | — | 车辆穿模无障碍——物流几乎无阻力 |

**设计洞察**：传送带升级是否"线性"（只是速度翻倍）还是"行为改变"（如 Factorio 的地下带改变空间拓扑、Shapez 2 的空间列车改变运输范式、Satisfactory 的提升机引入垂直维度）决定了这款游戏物流系统的深度上限。

#### 5.2.2 车辆/火车/无人机物流

| 层级 | Factorio | Satisfactory | DSP | CoI | ONI |
|------|----------|-------------|-----|-----|-----|
| **初级** | — | 拖拉机→卡车 | — | 卡车（主力） | — |
| **中级** | 自动化火车（信号系统） | 电力火车（Block/Path Signals） | — | 火车 T1/T2 | — |
| **高级** | 物流机器人（箱网络） | 无人机 | 星际物流船 | — | 传送带轨道+清扫器 |
| **终极** | Space Age 星际平台 | 传送门（Tier 9） | 星际物流站（ILS） | — | 轨道炮（跨行星） |

**关键对比**：
- **Factorio 的火车信号系统**是品类最真实/最复杂的——基于现实铁路原理（区块信号+链式信号），是著名的新手难点，也是老手最爱的深度系统
- **Satisfactory 的火车**使用电力而非燃料，轨道需物理铺设，有碰撞体积——也是最"物理"的火车系统
- **DSP 的 ILS 系统**是最简洁的跨行星物流解决方案——但代价是缺乏细节优化空间
- **CoI 的卡车为中心**是品类唯一的"车辆优先"设计——传送带只是补充

#### 5.2.3 机器人/自动化分拣

- **Factorio 施工机器人**——品类黄金标准。按蓝图自动建造，让玩家从"手放一切"升级为"设计蓝图→机器人建造"。物流机器人从箱网络自动搬运物品。这是 Factorio 后期工厂规模飞跃的核心推手。
- **ONI 自动清扫器+传送带轨道**——更接近"自动化分拣系统"而非万能机器人。需要物理铺设轨道，但可以构建非常复杂的逻辑分拣网络（轨道元素传感器 + 自动卸货器）。
- **Satisfactory 无建造机器人**——这是最大的系统性差距。蓝图需要物品在背包中，不能自动建造。建造大型工厂是纯粹的"苦力"。
- **Cosmoteer 船员**——品类最独特的"物流载体"——模拟人类搬运弹药/电池/资源。效率取决于走廊布局（步行距离）和角色优先级分配。

#### 5.3.2 副产物/废料管理机制对比

这是区分"硬核"和"休闲"自动化游戏的关键维度：

| 游戏 | 副产物管理 | 设计评价 |
|------|-----------|---------|
| **Captain of Industry** | **最硬核**——几乎所有机器产生副产品。废气需排放/处理，污水需净化（全域水污染惩罚），矿渣需倾倒，核废料需后处理。忽视副产品 = 死亡螺旋 | 品类中副产品管理的巅峰 |
| **ONI** | **极硬核**——电解水产氢（爆炸风险+需分离），发电机产CO₂（窒息），精炼金属产热量（杀死作物）。但热量可通过蒸汽涡轮机"删除"，CO₂可喂养滑皮斯特或排放太空 | 物理模拟使副产物管理有"工程设计"的成就感 |
| **Factorio** | **中等**——石油加工有轻重油副产物（可通过裂解转化或用作燃料），铀加工有 U-238 副产物（可用于弹药或增殖为 U-235）。大多数副产物可被利用但有管理成本 | 基础版副产物管理不重；Space Age Gleba 腐败+腐败物处理大幅提升了这一维度 |
| **Satisfactory** | **极轻**——绝大多数配方无副产物。核废料是唯一永久存在不可删除的副产物（需永久储存）。铝土矿精炼有少量副产物水（可循环回系统） | 刻意设计为"放松"——不会因副产物堆积而崩溃 |
| **DSP** | **极轻**——精炼油有副产氢（可燃烧或存储），除此之外几乎无副产物概念 | ILS 的"无限存储+无限运输"使管理变得无压力 |
| **Mindustry** | **极轻**——无传统副产物概念。资源节点永不枯竭 | 设计重点不在副产物管理 |
| **Shapez** | **无**——不存在副产物 | 属于另一品类（纯解谜） |

### 5.4 压力机制对比

压力机制是自动化游戏品类中最被低估的设计维度——它从根本上决定了"玩游戏的感受"。

```
                    外部压力强度
                          ↑
            Mindustry    │
            (波次进攻)    │  Riftbreaker
                          │  (波次+探索危害)
                          │
            Factorio     │  Captain of Industry
            (污染+虫子)   │  (死亡螺旋)
                          │
            ONI          │
            (生存需求)     │
                          │
  ────────────────────────┼──────────────────────→ 压力可关闭性
                          │
            DSP(可选黑雾) │
            Satisfactory  │  Planet Crafter
            (仅野生动物)   │  (前期生存)
                          │
            Shapez       │
            Infinifactory │  Astroneer
            Plan B       │  (无压力)
            (零压力)      │
                          ↓
```

#### 5.4.1 五种压力类型

**1. 敌人/战斗压力**
- **Factorio**：虫子由污染吸引，进化因子只增不减。可关闭（和平模式），但关闭会同时禁用军事研究树的大部分内容
- **Mindustry**：波次敌人 + 自主反攻。敌人路径固定，需围绕防守布置后勤。不可关闭（核心玩法）
- **DSP 黑雾**：完全可选（可关闭/被动/静默模式）。高等级黑雾掉落独特组件。太空战斗未完成
- **Satisfactory**：仅野生动物，不攻击工厂。可关闭敌对生物
- **Riftbreaker**：战斗是核心循环，不是压力而是输出

**2. 资源枯竭压力**
- **Factorio**：矿脉有限（除水/油），必须持续向外扩张
- **Satisfactory/DSP/Mindustry**：矿点永不枯竭——消除了一种核心压力，改变了游戏的"紧迫感"
- **CoI**：地图上铁和铜有限，后期必须依赖进口合同和回收法令
- **ONI**：藻类/煤炭不可再生，但替代方案（电解水/哈奇养殖/太阳能）很早就可用

**3. 生存需求压力**
- **ONI**：最强——呼吸、进食、膀胱、体温、士气、压力，六个维度需持续管理
- **CoI**：强——食物四类多样性、水资源、疾病、凝聚力。死亡螺旋不可逆
- **Planet Crafter**：前期有氧气/食物/水需求，后期形同虚设
- **Riftbreaker**：无传统生存压力（机甲不饥不渴）

**4. 空间限制压力**
- **Mindustry / Assembly Line**：有限地图——布局效率成为核心约束
- **Shapez**：建筑免费但空间是真正的稀缺资源
- **DSP**：每行星表面积固定——迫使星际扩展
- **Satisfactory / CoI**：手工地图提供有限但足够大的空间
- **Factorio**：几乎无限——空间压力最小

**5. 纯优化无压力**
- **Shapez**：零战斗、零资源成本、零时间限制——"禅意"自动化
- **Infinifactory**：无任何外部压力——纯智力挑战
- **Plan B**：无失败状态——纯粹星球改造

#### 5.4.2 压力类型对玩法体验的影响

| 压力类型 | 心理效果 | 适合的玩家 | 不适合的玩家 |
|----------|---------|-----------|-------------|
| 敌人/战斗 | 紧迫感、防御规划的战略性、"从危机中幸存"的满足感 | 喜欢多线操作、策略规划的玩家 | 纯建造爱好者、减压型玩家 |
| 资源枯竭 | 持续的扩展动力、"不扩张就死亡"的推动力 | 喜欢探索和扩张的玩家 | 喜欢"完美永久工厂"的玩家 |
| 生存需求 | 复杂系统管理的沉浸感、"从蛮荒到文明"的叙事弧 | 生存/殖民模拟爱好者 | 只想专注自动化的玩家 |
| 空间限制 | 布局优化的紧迫性、创造性压缩的满足感 | 解谜爱好者、空间思维强者 | 喜欢宏大扩展的玩家 |
| 零压力 | 纯粹心流、创造性自由、减压体验 | 休闲玩家、禅意建造爱好者 | 需要外部驱动力和目标感的玩家 |

**关键设计教训**：最优压力水平是**高度个人化的**。Factorio 的成功部分归功于其"可配置的压力"（可关闭虫子、可调整资源丰度、可调整进化速率），而 Satisfactory 的成功说明了"无压力自动化"同样有庞大的市场。**不是所有自动化游戏都需要战斗或生存压力**——Shapez 和 Infinifactory 证明了纯优化可以自成一派。

## 七、品类趋势与洞察

### 7.1 工业自动化游戏的发展趋势

**1. 从"单一平面"到"多维度空间"**

2016 年 Factorio 奠定的 2D 俯视范式正被多维空间游戏挑战：
- **垂直维度**：Satisfactory 的自由 3D 垂直建造 → 催生了"建筑设计"子文化
- **球面维度**：DSP 的球面行星 → "在球面上搞物流"是全新的设计空间
- **多表面维度**：Factorio Space Age 的四星球 + 太空平台 → 供应链在多重力环境下运行
- **星际维度**：DSP 的跨星系 ILS 网络 → 物流规模感超越单个"地图"的限制

**2. 从"传送带拼图"到"多维物流"**

品类的物流系统正从"如何连接 A 到 B"扩展到更大的设计空间：
- Shapez 2 的空间列车 → 模块化岛屿间的物流
- Satisfactory 的传送门（Tier 9）→ 即时传送替代传统运输
- DSP 的 ILS → 最简洁的跨行星物流方案
- CoI 的舰船 → 将世界地图贸易整合到工厂建设中

**3. "去生存化"作为独立路线的确立**

Shapez 1/2 的商业成功（650,000-700,000 份 EA 销量, 97% 好评率）证明了**纯自动化解谜**不是"Factorio 的简化版"，而是有自己的市场。Plan B 和 Shapez 共同确立了一个独立于"压力驱动"的"禅意自动化"子品类。

**4. 生存模拟 + 自动化的融合加深**

ONI 和 CoI 证明了自动化不只是工厂游戏的核心，也是生存模拟游戏后期必须借重的系统。未来可能看到更多"文明建设"型游戏将自动化作为从"手工蛮荒"到"工业文明"的过渡机制。

**5. Mod 生态成为长期留存的决定性因素**

Factorio 的 5,000+ Mod 生态是其 1,000+ 小时留存的核心原因。Mindustry 尽管 Mod 可用但规模远小于 Factorio——这限制了它的长期深度。Satisfactory 的非官方 Mod 管理器和较小的 Mod 生态也被部分社区成员认为是一个弱点。

### 7.2 设计模式的收敛与分化

**收敛的设计模式**：
- **传送带分合流**：几乎所有游戏都实现了某种形式的传送带+分流器/合流器（Factorio/Mindustry/Satisfactory/Shapez/DSP/Assembly Line）
- **蓝图系统**：从 Factorio 首创后成为品类标配，但实现质量差异巨大
- **递增式复杂度**：科技树/里程碑的递进结构已成为共识——先简单再复杂

**分化的设计模式**：
- **物流载体选择**：传送带优先（Factorio）vs 车辆优先（CoI）vs 火车唯一（Railgrade）vs 船员步行（Cosmoteer）
- **资源模型**：有限且枯竭（Factorio/CoI）vs 无限且恒定（Satisfactory/DSP/Mindustry）——这从根本上改变了游戏节奏
- **失败状态**：不可逆死亡螺旋（CoI/ONI）vs 重建可能（Factorio）vs 无失败（Shapez/Satisfactory/Plan B）
- **空间组织**：无限扩张（Factorio）vs 有限岛屿/行星（CoI/DSP）vs 有限网格（Assembly Line）vs 关卡独立空间（Infinifactory/Railgrade）
- **自动化作为核心 vs 自动化作为工具**：品类正在分裂为两个方向——Shapez/Factorio/DSP 的"自动化即目的" vs ONI/CoI/Planet Crafter 的"自动化即手段"

### 7.3 中国开发者的贡献

**戴森球计划（柚子猫工作室, 重庆）**

5 人初始团队，全球销量超 300 万套，Steam 97%+ 好评。中国独立游戏在全球自动化品类中最成功的案例。关键成就：
- 在激烈的品类竞争中找到了独特的"球面+星际"定位
- ILS 系统的简洁性是品类领先水平
- 在"内容导向而非时间导向"的开发哲学下，所有大型更新免费
- 从 Kickstarter ~10 万元 + 摩点 ~10 万元起家，未依赖外部融资

DSP 的成功证明了中国独立团队在全球化品类中有能力竞争。当前"创建系统"（载具+空间站）的完成质量将是判断其长期地位的关键。

**Mindustry（Anuke）**虽然不是中国团队，但在中国 Steam/移动社区有庞大的中文玩家群体，且开源模式吸引了全球华语开发者参与 Mod 制作。逻辑处理器系统激发了一批中文编程社区（如 Pyndustric 编译器、中文教程和 Wiki）。

### 7.4 社区模组生态的重要性

**四级 Mod 生态模型**（从最弱到最强）：

| 级别 | 特征 | 代表游戏 |
|:--:|------|------|
| Lv1 | **无原生 Mod 支持，依赖外部社区** | Satisfactory (ficsit.app + SMM 非官方管理器) |
| Lv2 | **有 Mod 基础支持，社区较小** | Mindustry (JSON/JS/Java 三层 API + Steam Workshop), ONI (Steam Workshop，但审核争议) |
| Lv3 | **开放架构，社区活跃但不如 Lv4** | DSP (r2modman + Thunderstore，有活跃 Mod 社区，但规模远小于 Factorio) |
| Lv4 | **品类黄金标准——完整开发者 API + 内置管理器 + 超大社区** | Factorio (自建 Mod 门户，5,000+ Mod，版本控制，存档级 Mod 配置) |

**模组生态对玩家投入时间的影响**：

- Factorio: 基础版 ~30-50 小时（火箭发射）；基础版 + 部分 QoL Mod ~50-100 小时；Krastorio 2 ~30 小时额外；Space Exploration ~300 小时额外；Pyanodon's ~500+ 小时额外
- Mindustry: 典型 50-150 小时；Mod 可延长至 200+ 小时（但远不及 Factorio 的 Mod 延长度）
- Satisfactory: 典型 80-150 小时；Mod 社区较小——主要提供 QoL 改进而非内容扩展

**关键洞察**：Mod 不是在游戏"完成后"才变得重要——它是**深度玩家的自然延伸路径**。一个游戏能否将 50 小时的玩家转化为 500 小时的玩家，几乎完全取决于 Mod 生态的质量。Factorio 的研究者模型（内置 Mod 管理器，版本控制，存档级配置）应当成为品类参考的标准设计。

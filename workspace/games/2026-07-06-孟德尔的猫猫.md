## 二、Cat Coat Genetics 完整覆盖

### 2.1 基因座选择

基于真实猫毛色遗传学，选取核心基因座：

| 基因座 | 基因/蛋白 | 染色体 | 遗传模式 | 性状 | 教学点 |
|--------|----------|:--:|---------|------|--------|
| **O (Orange)** | *ARHGAP36* | X | 共显性 | 橘色/黑色/玳瑁 | 伴性遗传、X 失活 |
| **B (Brown)** | *TYRP1* | 常 | 复等位, B>b>b¹ | 黑/巧克力/肉桂 | 复等位基因 |
| **D (Dilute)** | *MLPH* | 常 | 隐性 | 色素稀释（黑→蓝/橘→奶油） | 隐性上位 |
| **W (White)** | *KIT* | 常 | 显性 | 全白（遮盖一切） | 上位性 |
| **S (Spotting)** | *KIT* | 常 | 不完全显性 | 白斑（0%~90%） | 可变表现度 |
| **A (Agouti)** | *ASIP* | 常 | 隐性 | 虎斑底色/纯色 | 经典显隐性 |
| **T (Tabby)** | *Taqpep* | 常 | Mc>b (鲭鱼>经典) | 条纹形状 | 复等位基因 |
| **C (Colorpoint)** | *TYR* | 常 | 多等位, C>cb>cs>c | 重点色（暹罗/缅甸/白化） | 温度敏感型酶 |
| **L (Length)** | *FGF5* | 常 | 隐性 | 短毛/长毛 | 入门教学 |
| **F (Fold)** | *TRPV4* | 常 | 显性+纯合致死 | 折耳（Ff=折, FF=软骨病） | 致死等位基因+伦理 |

### 2.2 为什么加 C 基因座

没有 C 基因座就无法生成暹罗猫、布偶猫、缅甸猫。这三个是世界上最知名的纯种猫品种之一。

```
C (完全显性) > cb (缅甸, 轻度重点色) > cs (暹罗, 重度重点色) > c (白化)

cs/cs = 暹罗式重点色：身体热区浅色、耳/脸/尾/爪冷端深色
cb/cb = 缅甸式：全身略深，重点色对比度低
c/c = 白化（红眼，完全无色素）
```

温度敏感机制：TYR 酶在正常体温（~38.5°C）下活性低 → 身体产色素少 → 浅色。在耳/尾等较冷的末端酶活性恢复 → 深色。**这是猫遗传学中最直观的「基因×环境交互」案例。**

### 2.3 品种特有性状（非毛色）

| 性状 | 基因 | 遗传 | 视觉效果 |
|------|------|:--:|------|
| 折耳 | F (TRPV4) | 显性, 纯合致死 | 耳朵前折 |
| 卷耳 | Cu (未知) | 显性 | 耳朵向后卷 |
| 无尾 | M (Manx) | 显性, 纯合致死 | 无尾/短尾 |
| 卷毛 | re (Cornish Rex) / se (Selkirk) | 隐性 | 卷曲毛发 |
| 短腿 | Mk (Munchkin) | 显性, 纯合致死 | 腊肠猫 |
| 多趾 | Pd (Polydactyly) | 显性 | 6+ 脚趾 |
| 异色瞳 | 白斑+随机发育 | 非遗传 | 一眼蓝一眼铜 |

### 4.2 「意外」是内容引擎

遗传学的自然结果创造不断的惊喜：

```
两只黑猫 → 生出蓝灰色小猫
  （父母都是 B- Dd → 1/4 dd 稀释后代）

全白猫 × 黑猫 → 生出橘色小猫
  （白猫是 Ww → 脱去 W 遮盖 → 真实基因型是 O-）

两只短毛猫 → 生出长毛猫
  （父母都是 Ll → 1/4 ll）

橘猫 ♂ × 黑猫 ♀ → 生出三花猫（但全是母的！为什么？）
  （父 o♂ × 母 OO♀ → 女儿全部 Oo 玳瑁，公猫全橘）
```

这些不是 scripted 事件——是遗传规律的自然涌现。玩家不需要理解遗传学就能体验到「意外」的快乐。好奇的玩家可以点开知识卡片学习为什么。

### 4.3 育种辅助（降低门槛）

玩家不需要手动计算 Punnett 方块。游戏提供：

```
┌───────────────────────────────────────────┐

│                                           │
│  ♀ 咪咪（玳瑁短毛）  ×  ♂ 橘子（橘色长毛）    │
│                                           │

│  · 25% 橘色短毛母猫                        │
│  · 25% 黑色短毛母猫                        │

│  · 12.5% 三花长毛母猫  ← ⭐ 新花色！        │
```

「看基因推理过程」是可选面板——遗传学爱好者可以深入学习。

## 五、引导与教育

### 5.1 知识发现而非教程灌输

每个图鉴条目附带一个微型知识卡片，采用「你先看到现象 → 然后得到解释」的顺序：

```
🐱 解锁：三花猫（Calico）

你观察到了：
这只猫同时有橘色、黑色、白色三种颜色。
而且——它是母猫。

为什么？
→ 橘色基因在 X 染色体上
→ 母猫有两个 X，可以同时携带橘色+黑色
→ 白色来自另一个独立基因（白斑）
→ 公猫只有一个 X，无法同时拥有橘色和黑色
   （除非是罕见的 XXY 公猫，概率 ~1/3000）

📖 你学到的概念：伴性遗传、X 失活、共显性
```

### 5.2 叙事事件：折耳猫

```
阶段1：玩家获得/培育出第一只折耳猫 — "好可爱！"
阶段2：玩家尝试折耳×折耳配对 — 系统警告"不建议"
阶段3：如果玩家仍然配对 — 小猫出现骨骼问题
阶段4：知识解锁 — 折耳软骨发育不良：纯合 FF 致病
阶段5：伦理选择 — 只让折耳×立耳配对（Ff×ff）
```

这是《孟德尔模拟器》（豌豆版）完全做不到的情感教育。

### 5.3 「常见猫是如何选育出来的」

图鉴中可以穿插真实品种的选育历史：

- **暹罗猫**：泰国皇室培育，cs 基因产生温度敏感的重点色。为什么小猫出生时是全白的？（子宫内温度均匀 → 出生后体表降温 → 重点色逐渐出现）
- **苏格兰折耳猫**：1961 年苏格兰农场一只自发突变折耳猫。所有折耳猫都是它的后代。FF 纯合致软骨发育不良——伦理争议至今。
- **三花/玳瑁**：不能作为一个「品种」——因为公猫几乎不能是三花。三花是一种基因型表现，而非品种。

## 六、经济与进度

### 6.1 图鉴结构

```
基础图鉴：50 个条目
  ├─ 毛色系（15）：橘色系 / 黑色系 / 白色系 / 灰色系 / 重点色系
  ├─ 花纹系（10）：虎斑 / 玳瑁 / 三花 / 燕尾服 / 纯色
  ├─ 品种系（15）：暹罗 / 折耳 / 无尾 / 卷毛 / 布偶 / 英短 / 缅因 …
  └─ 稀有系（10）：异色瞳 / 多趾 / 自然突变体 / 黑白梵纹 / …

隐藏图鉴：≈ 10 个
  └─ 极低概率自然突变（类似 Factorio 品质系统 0.01% 传说级）

全图鉴完成 ≈ 60 条目 ≈ 2-4h
```

### 6.2 资源循环

```
配对产仔 → 小猫出生 → 选择：保留 / 送养（换金币）/ 交换（换新种猫）
    ↓                                              ↓
保留的猫长大 → 可用于下一轮配对              金币用于购买稀有种猫/特殊道具
    ↓
配对需要「配对券」（随时间和任务获取，非氪金）
```

**没有付费抽卡。没有盲盒。** 玩家想要什么猫 → 用遗传学定向培育。这是和《孟德尔模拟器》的盲盒系统最根本的区别。

## 七、美术策略

与「哈！基米之家」相同。三种策略：

| 策略 | 描述 | 优势 | 劣势 |
|------|------|------|------|
| A: 图层叠加 2D | 基础猫身 + 毛色层 + 花纹层 + 白斑面具 + 部件变体 | 一人可做 | 动画需适配部件 |
| B: Lowpoly 3D | 单模型 + 程序化材质 | 动画一次 | 3D 管线 |
| C: 像素风 | 32-64px 精灵 + 调色板替换 | 最快原型 | 细节受限 |

对于《孟德尔的猫猫》，策略 A（纸面手绘 + 图层叠加）最合适——可爱优先，不需要 3D 的复杂动画，也不需要行为系统那么深的动作需求。

### 关键部件拆解

```
基础图层（所有猫共享）：
  ├─ 猫身体轮廓
  ├─ 猫头部
  └─ 猫四肢+尾巴

可变图层（按基因型叠加）：
  ├─ 毛色底色（O + B × D 决定色值）
  ├─ 虎斑纹叠加（A + T 决定纹样）
  ├─ 白斑面具（S 决定覆盖区域，类似 shader mask）
  ├─ 重点色叠加（cs/cs 时应用于端部）
  ├─ 毛长修饰（L 决定毛发边缘的蓬松度）
  └─ 眼/耳/尾变体精灵替换
```

总计约 15-20 张基础素材 → 程序化叠加 → 百万级视觉变体。

## 十、未决问题

1. **纯图鉴收集的「粘性」够不够？** 《孟德尔模拟器》94% 好评但仅 17 条评价——样本太小。猫主题 + 分享机制能否破圈？

2. **要不要加极简的猫行为？** 猫在猫舍中走来走去、舔毛、睡觉——不可编程，但是可观察。这个做多少？

3. **猫的命名和个性化**：玩家可以给猫起名吗？每只猫有独特的性格描述（由隐性多基因生成）吗？

4. **育种是全自动还是半手动？** 「全自动」= 选目标→系统配对→等结果。「半手动」= 玩家自己选父母猫。对于图鉴收集，全自动更快；对于「探索遗传学」的乐趣，半手动更沉浸。

5. **没有行为编程，2h 内玩家的大部分时间在做什么？** 观察猫、浏览图鉴、制定育种计划、等小猫出生、欣赏新花色？还是需要加入更多互动（如猫玩具、拍照模式）？

6. **和「哈！基米之家」的开发顺序？** 这个更小、更独立——适合作为热身项目先做？还是两个并行？
